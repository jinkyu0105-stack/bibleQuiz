2026-09-23. **로컬 구현·필수 검사·상태 문서 갱신 완료.** 부모 Phase 5 진행 중. P5-56 완료 상태와 기존 미커밋 변경을 보존했다.

## 구현

- [정리 service](../../workers/_shared/services/draft-cleanup.ts): 미발행 한 설교 초안의 마지막 저장·수정+7일, 발행+7일과 하루 전 예정 조회. 현재 입력·콘텐츠·metadata·옛 이력·배치 선택·job/lease·발행·source 정책을 읽고 batch 안에서 다시 대조한다. 옛 metadata 시각 불명·영구 발행 자료 부족·유효한 호출 lease는 보류한다. 미발행 작업 단위는 2026-09-23 사용자 답변으로 확정했다.
- [0021](../../migrations/0021_phase5_draft_cleanup.sql)·[schema](../../workers/_shared/db/schema.ts): 불변 정리 기록과 앞으로의 metadata 저장 시각만 추가. 기존 표 재생성·행 변환·본문 backfill 없음. 불변 본문 삭제 guard 6개에 정리 표식 조건을 추가하고, 정리 뒤 본문 재삽입·새 생성·provider 호출을 막는다. ID/checksum/확정/usage/provenance FK는 남긴다.
- 정리 대상: 입력의 미확정 작업본·교정 비교, 옛 revision/교정·콘텐츠 본문, 새 콘텐츠 본문, generation context·배치/최종 ticket·옛 AI 감사의 비교 본문. 원본과 source별 최종 확정 문서는 기본 keep_private. native retention_mode가 명시적으로 delete_text_after_publish이고 checksum이 대응하면 본문만 제거하고 source metadata·checksum·확정 기록을 보존한다. operational audit와 비용/정식 콘텐츠는 제거하지 않는다.
- [API](../../workers/app/app.ts)·[DTO](../../shared/api/admin-draft-cleanup.ts): Access/no-store/strict query의 GET 예정 목록, 정리 완료 초안에 410 DRAFT_EXPIRED. 삭제 실행 HTTP API 없음. 본문·정답·actor·checksum·정리 대상 내부 ID 목록은 응답하지 않는다.
- [관리 화면](../../src/features/admin-sermon-input/DraftCleanup.tsx): 기존 승인 테마, 한국 시간의 예정/기한 경과/보류/완료 목록, 빈 상태·읽기 실패/재시도. 삭제/예외/기간 설정 버튼 없음. 이후 새 초안 시작 안내를 제공한다.
- [Content Worker](../../workers/content/index.ts): scheduled handler는 기존 하루 1회 운영 계약의 진입점만 연결. DRAFT_CLEANUP_ENABLED 기본 비활성. config에 Cron·remote DB binding을 추가하지 않았다. [실행 경계](../../workers/_shared/services/content-generation.ts)와 DB guard는 만료 자료로 새 유료 호출을 시작하지 못하게 한다.

## 보존·제외·폐기 접근

시작 HEAD main `0ab476e4281734f4eab64cc6231be09092221651`, 기존 파일 SHA **503개**를 `/tmp/p557-baseline.json`으로 먼저 기록했다. 최종 변경/보존은 [검증 JSON](P5-57-verification.json)을 따른다. 기존 데이터의 checksum 전체를 수집했다고 주장하지 않는다. 실제 앱/원격 D1에 접근·삭제·migration을 실행하지 않고 memory/임시 D1만 사용했다. stage/commit/push/reset 없음. 기존 0000~0020 migration·AGENTS·package/lock·wrangler 설정은 유지했다.
