## 구현과 검토

`design-taste-frontend`의 기존 디자인 보존 절차를 적용했다. 현재 Air 유리/시간대 팔레트·원형 버튼50px/모바일44px·포인터 광원·키보드와 접근성 이름을 기준으로, 아이콘 내부만 조정했다. 기존 잔디 SVG의 겹치는 여러 윤곽을 세 가닥의 선으로 줄였다. 새 장식/모션/패키지는 없다.

- `src/features/quiz/ThemeControl.tsx`: 잔디 아이콘과 꺼짐일 때만 렌더하는 사선/대비 테두리. 기존 공통 ThemeControl을 통해 모든 실제 화면에 반영한다.
- `src/styles/sky.css`: SVG 전체 opacity .55를 제거하고 풀잎만 .7로 낮춘다. 사선은 full opacity, 기존 glass-solid 팔레트의 테두리로 풀잎과 구분한다.
- 기존 잔디 활성은 OriginKit 캔버스, 비활성은 meadow 사진 복귀다. 사진/잔디 수/재생·시간대·저장 정책을 변경하지 않았다. 표시 글자는 없으며 ‘잔디 켜기/끄기’와 aria-pressed를 유지한다.
- 관련 기존 E2E에 켜짐/꺼짐 표식, SVG opacity와 새로고침 복원 확인을 추가했다.
