## 범위와 보존

- Preview D1에 새 고유 ID로만 추가한다. 기존 퀴즈/제출/대표 지정을 수정하거나 삭제하지 않는다. Production, migration/schema, Worker 배포, Secret/Access, AI 활성화/실제 API 호출, push는 포함하지 않는다.
- 초안은 제목/입력 본문을 편집할 수 있는 가상 자료다. AI 결과나 사람 검수·발행 증거를 조작하지 않는다. 공개3세트는 기존 합성 Preview fixture의 호환 발행 자료 형식으로 넣고 어린이/장년별 기존 퍼즐 엔진으로5문제씩 생성한다.
- 지난2세트×2난도×3명=12개 제출·코멘트. 난도별2명 완전 정답/1명 부분 답안, 각2명의 확정 순위. 가상 삭제 요청2개를 received로 접수하고 실제 삭제는 실행하지 않는다. 문의함 검수용이며 실제 사용자의 접수번호/세션을 만들거나 발송하지 않는다.
- 모든 제목/참여 이름/코멘트/문의는 테스트 표시. 성경 본문·실제 설교/개인 자료/유료 AI 결과는 사용하지 않는다. 합성 답안을 실제 AI 요약으로 표시하지 않도록 요약/AI provenance는 비운다. 영상 ID는 가상이며 영상/자막 조회는 하지 않는다.

## 환경·방법

Cloudflare MCP D1 조회는 인증 오류10000이었으나 기존 Wrangler 인증의 `d1 execute biblequiz-d1-preview --remote --env preview` 읽기는 성공했다. 현재 migrations39, sermons4, quiz_sets4, submissions1, privacy_requests0. 인증/권한 설정은 바꾸지 않았다. 기존 토큰은 출력하지 않는다.

Context7 `/cloudflare/cloudflare-docs`와 [공식 D1 import 안내](https://developers.cloudflare.com/d1/best-practices/import-export-data/)를 확인했다. SQL file 실행의 거래/실패 rollback·명시 BEGIN/COMMIT 제외·FK 순서를 지킨다. 처음의 새 translation PK가 동일 자료 재적용을 거부하고 기존 행 UPDATE/UPSERT를 쓰지 않는다. 유일한 UPDATE는 같은 거래 안에서 새 초안 input event를 sealed로 전환하는 기존 저장 규약이다.

## 로컬 준비·검사 완료

`buildPreviewDemo`가 고정 ID·격자·실제 채점 결과·입력 checksum을 만든다. 초기2글자 위주 후보는 인접 규칙으로 배치 실패해3글자 이상 연결 단어로 바꿨다. 새 입력을 공개 AI 요약으로 오인하지 않도록 summary를 null로 두었다. 초기 검사 경로 오류(variant.difficulty)와 Node 파일 준비 검사를 shared/browser 범위에 넣어 생긴 type 충돌은 fixture 쪽에서 바로잡았고 제품 코드/검증기를 완화하지 않았다.

공개 코멘트의 대괄호 테스트 표시는 기존 허용 문자 규약에 맞춰 `(테스트)`로 고쳤다. 임시 HTTP 검사에서 API 주소를 path 난도로 잘못 지정한 404는 실제 계약의 `?difficulty=`로 바로잡았다. 제품 코드와 계약은 바꾸지 않았다.
