SQL file 실행의 거래/실패 rollback·명시 BEGIN/COMMIT 제외·FK 순서를 지킨다. 처음의 새 translation PK가 동일 자료 재적용을 거부하고 기존 행 UPDATE/UPSERT를 쓰지 않는다. 유일한 UPDATE는 같은 거래 안에서 새 초안 input event를 sealed로 전환하는 기존 저장 규약이다.
