# P5-56 — 선택한 답·단서만 재생성

2026-09-23. **로컬 구현·필수 검사·STATUS/HANDOFF 갱신 완료.** 부모 Phase 5 진행 중. 실제 유료 호출·발행·원격 migration·배포·출력 제외.

## 구현과 보존

- 관리자 화면에서 어린이/장년 답·단서 하나와 현재 문제를 고른다. 비용과 무료 직접 수정 대안을 확인한 명시적 요청만 실행한다. 응답 유실 때 같은 요청 번호/대상을 유지한다.
- 기존 child/adult v2 실행과 1회 provider 호출, 불변 context/usage/outcome 저장을 재사용한다. 요청에 `candidateTarget`, 후보 단계에 `target`, 생성 operation에 `replacement`를 선택 필드로 추가한다. 기존 요청 바이트·schema SQL·migration은 변경하지 않는다.
- provider는 같은 문제 ID 하나만 반환한다. 도메인 검증이 ID/개수/중복 답·단서/한글 답/실제 근거/현재 의도·입력을 확인한다. 다른 문제와 순서, 사람 수정 근거 및 사용/반드시 포함/제외 상태를 서버가 보존한 전체 비교 snapshot으로 저장한다. AI에게 전체 문제를 재작성하게 하지 않는다.
- 새 결과는 자동 선택하지 않는다. 비교 화면에 기존 값/새 제안을 함께 표시하고 기존 선택 또는 새 자료 선택을 이어간다. 새 자료를 선택하면 해당 난이도 검수만 비우고 현재 배치 검토를 다시 요구한다. 과거 완료 증거·비용은 유지한다.
- 비교 뒤 현재 목록이 바뀌면 오래된 비교본 선택/복원을 거부해 다른 수정을 덮지 않는다. 불확실 호출은 자동 재시도하지 않으며 같은 요청 번호의 다른 대상은 거부한다. 비용 재확인 뒤 같은 난이도의 새 명시적 요청은 현재 목록의 대상을 사용하고 옛 불확실 호출/비용을 보존한다.
- Access/same-origin/strict body/no-store 및 실행 비활성 기본값을 유지한다. 새 production 의존성·서비스·migration 없음. 실제 앱/원격 DB를 변경하지 않았다.
