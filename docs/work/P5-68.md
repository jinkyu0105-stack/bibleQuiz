# P5-68 — 퀴즈별 AI 비용 상세 연결

2026-09-24. **로컬 구현·합성 검수 완료, 부모 Phase 5 진행 중.** [비용 명세](../spec/generation.md#p5-68-로컬-비용-상세-연결)와 [API](../spec/api.md#p5-68-퀴즈-ai-비용-조회-api)를 기존 관측 원장에 연결한다. 실제 provider/청구서/실데이터 검증은 이번 증거가 아니다.

## 사용자 동작과 코드

- 선택한 미발행 설교의 퀴즈 ID를 [SermonDrafts](../../src/features/admin-sermon-input/SermonDrafts.tsx)에서 부모 화면으로 전달한다. [관리자 입력 화면](../../src/features/admin-sermon-input/AdminSermonInput.tsx)의 고정 비용 pill은 선택한 퀴즈 전체의 관측 합계·호출 수·미확인 횟수를 표시하고, 버튼을 누르면 [상세 drawer](../../src/features/admin-sermon-input/AiCostDetails.tsx)를 연다. 생성 결과 새로고침과 자막 교정 요청·상태 확인 뒤 비용도 다시 읽는다. 발행된 퀴즈는 기존 [발행 정보 화면](../../src/features/admin-sermon-input/PublishedMetadata.tsx)에서 같은 상세를 연다. 달력 주간/현재 작업 비용은 기존 생성 화면에 명시적으로 별도 표시한다.
- [관리자 GET API](../../workers/app/app.ts)와 [읽기 서비스](../../workers/_shared/services/admin-ai-costs.ts)는 `quiz_set`의 `ai_provider_calls`를 기준으로 현재 `ai_usage_observations`를 우선, 옛 `ai_usage_events`를 대체값으로 읽는다. 같은 호출을 중복 합산하지 않는다. 미보고 호출의 token/가격표/비용은 null이며 알려진 합계에만 관측 금액을 더한다. provider/model별 소계와 전체 수를 반환한다. 자막 교정, 의도·비판·요약·어린이·장년, 옛 감사 이력을 구별한다. 현재 개별 문제 재생성의 저장된 요청 맥락에 대상이 있으면 `singleEntry`로 구별한다. 요청 맥락이 정리되거나 읽을 수 없는 과거 호출은 원장의 범위(어린이/장년) 그대로 표시한다.
- [엄격한 응답 계약](../../shared/api/admin-ai-costs.ts)과 [클라이언트 검증](../../src/features/admin-sermon-input/client.ts)을 추가했다. 조회는 기존 Access 관리자 인증과 `private, no-store`, query 금지, 안전한 404/503 경계를 따른다. 공개 직렬화와 정답/비공개 자막에는 비용 응답을 넣지 않는다. 저장된 모델명·호출 당시 `pricingVersion`·micro-USD 추정치만 표시하고 현재 가격으로 과거 기록을 다시 계산하지 않는다. 가격표 수치 자체는 원장에 저장되지 않으므로 과거 버전의 단가를 추측해 채우지 않는다.

## 검사

- 합성 D1/provider: 관측 1회 USD 0.000524 + 응답 유실 1회, 모델 소계·토큰·가격표 버전·미확인 null, Access 401/정상 200·no-store, GET 전후 원장 동일 확인. 발행 뒤 본문 정리에도 비용 응답 동일. 개별 문제 합성 실행에서는 기존 요청 맥락으로 `singleEntry`가 참임을 확인했다. 실제 네트워크 provider 호출은 없다.
- 합성 API 기반 Chromium 데스크톱/모바일 각 1건: 미발행 퀴즈 선택을 바꾸면 pill과 drawer가 해당 퀴즈 비용으로 바뀌고, 모델·revision·가격표·미확인 안내와 좁은 화면 가로폭을 확인했다. 실제 기기/원격 Preview 검사는 아니다.
- **`pnpm check` exit 0**: lockfile/Cloudflare 설정·Drizzle·임시 Preview fixture·lint·typecheck·build, 단위 **31파일/273건**, Worker **74파일/1,988건**, Workflow **1파일/3건** 통과. 로그 `/tmp/p5-68-final-check.log`. 합성 Chromium 데스크톱/모바일 **2건 통과** (`/tmp/p5-68-e2e-final.log`).
- 초기 화면 검사는 날짜 서식 옵션 충돌로, 첫 전체 검사는 React effect 동기 state 규칙으로, 개별 문제 대상 검사는 내부 요청 맥락 ID가 엄격 응답에 섞인 문제로 실패했다. 날짜 옵션을 정정하고 로딩 갱신을 사용자 동작으로 옮겼으며 응답 필드를 명시적으로 제한한 후 관련 검사를 재실행했다. 완료 증거에는 통과한 최종 실행만 사용한다.
