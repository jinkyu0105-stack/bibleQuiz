# P5-55 — 의도만 재생성

2026-09-22. **로컬 구현·필수 검사 완료.** P5-54의 로컬 구현과 필수 검사가 완료된 상태에서 시작했다. 기존 광범위한 미커밋 변경, 실제 데이터와 이전 AI 비용을 보존했다.

## 구현

- 의도만 재생성은 별도 v2 작업에서 분석과 비판 검토를 순차 실행한다. 결과는 비교용 revision이며 기존 선택 의도를 자동으로 덮지 않는다. 새 결과를 사람 선택·재확정하면 하위 요약·문제 검수와 배치 선택을 무효화한다. 의도 작업 재개는 후속 요약·문제 AI 호출 없이 완료된다.
- 두 번째 호출이 거절되거나 결과가 불확실해도 첫 분석과 관측 사용량을 보존한다. 명시적 `retryCritiqueOnly` 요청은 새 intent 작업과 불변 출처 행을 원자 저장하고, 이전 성공 분석을 확인한 뒤 비판 검토 **한 호출만** 실행한다. 옛 호출 비용이나 사용량 미확인을 덮지 않는다. 자동 재호출은 없다.
- 관리자는 비용과 무료 직접 검토 대안을 확인한 뒤 비판 검토만 다시 시도할 수 있다. 비교 뒤 새 결과를 선택·재확정하거나 **기존 의도를 유지하고 비교 종료**할 수 있다. 종료는 기존 선택을 재확인한 뒤 active 작업을 해제한다. 이미 새 의도를 선택한 경우 기존 선택 유지 종료를 거부한다. 이 로컬 종료 동작은 이전 자동 승인 검토에서 범위 확대라는 이유로 거부됐지만, 이번 대화에서 사용자가 명시적으로 승인했다.
- 0019는 full v3 검수 대기와 intent v2의 좁은 공존 및 완료 증거를 연결한다. 0020은 기존 표를 재작성하지 않고 재시도의 분석 출처 테이블과 단계·대기·완료 증거만 추가한다. Drizzle schema, SQL, snapshot, journal을 함께 보관한다.
- 관리자 API는 Access, same-origin, strict body, no-store 경계 안에서 실행된다. 새 production 의존성·서비스는 없다.

## 검사

- 비판 검토 실패가 불확실한 경우와 거절된 경우 각각 첫 분석을 재사용해 새 작업의 모의 AI 호출이 정확히 1회임을 Worker 통합 검사로 확인했다. 분석/비용 보존, 명시적 사람 선택 후 완료, 기존 의도 유지 종료·active 슬롯 해제, 새 의도 선택 뒤 종료 거부도 통과했다.
- Chromium·모바일 Chromium에서 의도 비교·재확정 및 비판 검토만 재시도 요청·비교 종료 버튼 상태를 포함한 재생성 화면 4건 통과. 기존 요약 재생성도 포함한다.
- 채워진 임시 D1의 0018→0020 보존 검사 통과: 기존 62개 표의 모든 값/BLOB 유지, 기존 222개 trigger 중 검토된 교체만 변경, FK/quick_check 정상. 앱·원격 DB에는 적용하지 않았다.
- **최종 `pnpm check` exit 0**: lock/Cloudflare 설정/Drizzle/Preview fixture/lint/typecheck, unit 30파일 271건, Worker 64파일 1,881건, Workflow 1파일 3건과 빌드 통과. 무제한 병렬 Worker 실행은 로컬 workerd가 외래키 실패 경계 테스트 뒤 멈춰 중단했다. 4개 병렬·상세 출력의 전체 Worker 검사가 exit 0으로 통과하여 이 설정을 `vitest.worker.config.ts`에 반영한 뒤 정확한 `pnpm check`를 다시 실행해 exit 0을 확인했다. `git diff --check`와 문서 참조 확인도 통과했다.
