# P5-66 — 공개 영상 정보·자막 취득의 관리자 연결

2026-09-24. 완료 — 로컬 구현·합성 검수·전체 필수 검사·상태 문서. 부모 Phase 5 진행 중. P5-65 완료는 유지한다.

## 구현 경계

- 기존 계정 없는 공개 자막 adapter는 명시 주입한 transport로 영상 player를 조회한다. 같은 응답에서 검증 가능한 제목·게시일을 관리자 미리보기에만 제공한다. 자막 결과의 안전 진단과 비공개 본문은 분리한다. 실제 provider 성공률을 주장하지 않는다.
- 새 등록 폼은 video ID 중복을 provider 호출 전에 확인하고 기존 작업을 안내한다. 신규 영상은 조회된 제목·게시일·자막 상태만 보여주며 저장하지 않는다. 기존 날짜 후보 함수로 제목 앞 날짜 또는 게시일 기준 최근 일요일을 추천한다. 사람이 제목·설교일·장절을 확인해야 등록된다.
- 입력자료가 아직 없는 미발행 작업에서 공개 자막 원본 저장을 명시적으로 누르면 저장된 video ID로 다시 취득한다. 기존 첫 source 조건부 저장을 재사용하고 시간 구간·SHA·provider 출처를 불변 원본에 보존한다. 자막 30,000 Unicode code points 초과는 무기록 거부한다. 원본 저장이 사람 확정이나 AI 실행을 일으키지 않는다.
- 조회/취득 실패는 원문·signed URL 없이 고정된 실패 문구와 안전한 진단 부분집합을 보여준다. 다시 시도와 기존 수동 붙여넣기가 가능하다. 관리자 현재 입력 응답이 provider의 .ko track ID를 거부하던 계약 불일치를 고쳤다.
- 새 migration·의존성·외부 서비스·보존 기간은 없다. 0000~0028과 기존 미커밋 변경은 보존한다.
