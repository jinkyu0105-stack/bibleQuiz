## 연결한 동작

- [관리자 폼](../../src/features/admin-sermon-input/PublishedWording.tsx)은 기존 발행 정보 정정 아래에서 요약/난이도별 단서를 선택하고 수정 전후·종류·사유를 확인한다. 의미/난이도/정답 유도 불변은 사람이 확인한다. 의미 변경 또는 불확실 판단은 저장하지 않고 P5-61로 안내한다. AI/문자열 거리로 의미를 자동 인증하지 않는다.
- [DTO](../../shared/api/admin-wording.ts)와 [서비스](../../workers/_shared/services/published-wording.ts)는 현재 값·정정 번호·콘텐츠 revision·대상 소속·진행 중 오류 처리를 commit 때 재검증한다. 같은 요청·내용·관리자만 응답 유실 뒤 재생한다. 실패 시 UI 입력을 유지하고 명시적 최신 조회를 제공한다.
- [0028](../../migrations/0028_phase5_wording_corrections.sql)은 새 불변 표시 이력/공개 문구 view와 보호 trigger만 추가한다. Drizzle schema 수정→generate→SQL 검토 순서를 지켰다. 기존 표/trigger·최초 snapshot·문제/정답·채점 revision·제출/성적·순위·비용·기간·slug는 재작성하지 않는다.
- [공개 읽기](../../workers/_shared/repositories/public-quiz-repository.ts)는 현재/지난 퀴즈에 표시 정정을 적용한다. 요약은 콘텐츠 버전, 단서는 exact entry ID에 귀속하므로 교체된 문제에 옛 표시가 되살아나지 않는다. [철회 원본](../../workers/_shared/services/quiz-withdrawal.ts)을 통해 다음 철회/P5-61 검토에 현재 표시 문구를 전달하고 원래 정답을 유지한다. 반복 철회의 본문/원본 캡처 경합도 일치 검사로 거부한다.
- 새 서비스·의존성·AI 호출 없음. 기존 공개 문구 길이(요약 20,000자·단서 2,000자)와 관리자 콘텐츠 JSON 경계를 재사용했다. 새 의미 판정 정책·출력 제한을 만들지 않았다.
