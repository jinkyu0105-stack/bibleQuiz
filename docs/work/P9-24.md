## 구현

- `HomeEffectsControl`·`EffectControls`: 반사/빛줄기/비단결/오로라 네 선택과 공통 제어판. 각 효과를 켜면서 열기, 같은 열린 버튼을 다시 눌러 끄기, 닫기/Escape는 효과 유지와 해당 초점 복귀. PC60×266px, 모바일220×44px 목록은 기존 바 위로 열려 재생/선명하게/잔디의 자리를 유지한다.
- `veil-settings`: speed50을 추가해 옛 저장값의 너비/밝기/퍼짐을 보존한다. `flow-settings`는 두 새 효과의 유효값/기본값과 별도 브라우저 저장을 맡는다. 비단결50/50/50, 오로라55/50/50. 밝기10~100·크기/너비0~100·속도0~100. 기본 두 새 효과 끔.
- `hero-effects`: 한 캔버스·최대640×480/DPR1/30fps. 네 효과의 시간을 별도로 누적해 속도0 정지와 조절 순간 연속성을 보존한다. 비단결은 옆으로 흐르는 주름/명암, 오로라는 위로 감기는 빛기둥이다. 새벽 보라·낮 청색·노을 산호/금빛·밤 보라/은빛, 기존 영상/유리·메인 범위·숨김/정지/접근성·컨텍스트 복구를 공유한다.
