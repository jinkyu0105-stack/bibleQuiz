# P5-53 — 요약·난이도별 개별 재생성 실행 연결

상태: **완료 — 로컬 구현·필수 검사·STATUS/HANDOFF**. 부모 Phase 5 진행 중. 실제 유료 호출·발행·원격 migration·배포·출력 구현은 제외한다.

## 사용자 흐름

전체 생성의 내용 검수 단계 또는 생성 완료 뒤에 요약·어린이·장년 중 필요한 범위만 명시적으로 다시 생성한다. 기존 입력/확정 의도를 서버가 읽어 요청 범위의 provider를 1회 호출한다. 새 결과는 비교 자료로 보존하고 기존 선택본과 검수는 자동 교체하지 않는다. 선택·수정하면 해당 검수를 비우며 현재 배치 검토를 다시 확인해야 한다. 비교 결과가 추가될 때도 content revision이 증가하므로 이전 final ticket은 보존하되 현재 검토로 재사용하지 않는다.

화면은 비용 예시·직접 수정 무료안·전체 대신 한 범위 호출 대안을 표시하며 확인 뒤 요청한다. 같은 탭에서 응답이 유실되면 같은 requestKey로 확인한다. 확인 중 바탕 자료가 바뀌고 해당 요청이 이력에 없으면 사람이 명시적으로 새 요청을 준비할 수 있으며 비용 확인을 초기화한다. 성공/실패/불확실·관측 비용/미확인 호출을 이력에 표시한다. provider 응답 불확실 때 자동 재호출하지 않으며 같은 범위의 명시적 새 요청만 이전 작업을 stale로 남기고 실행한다. 기존 결과·비용은 삭제하지 않는다. 현재 선택본 외 과거 생성/수정본도 페이지 단위로 비교·선택할 수 있다.

## 구현 경계

- [개별 요청](../../workers/_shared/services/content-regeneration.ts): strict scope/version/소유 관계, 확정 의도의 현재 입력 적합성, 같은 요청 재생과 다른 scope 충돌, 불확실한 이전 작업의 명시적 교체. 기존 lifecycle request/dispatch/finish를 사용한다.
- [공유 실행기](../../workers/_shared/services/content-intent-generation.ts)·[진입점](../../workers/_shared/services/content-generation.ts)·[reader](../../workers/_shared/services/generation-domain-reader.ts): 기존 전체 생성 5단계와 개별 1단계를 분리한다. 봉인된 자료·실제 Zod/근거 검증·관측 usage·조건부 outcome 저장을 공유한다. 새 result 자동 채택·최종 AI 감사·자동 provider 재시도 없음.
- [관리자 API](../../workers/app/app.ts)·[DTO](../../shared/api/admin-content-generation.ts): `/generation/regenerate`, content 조회 `?before=<content_sequence>`와 `historyCursor`, 개별 작업 이력/비용. Access·same-origin·strict body·opt-in·private no-store 경계 유지. 현재 full job과 placement 소유권을 부분 job으로 교체하지 않는다.
- [화면](../../src/features/admin-sermon-input/ContentRegeneration.tsx)·[기존 편집 화면](../../src/features/admin-sermon-input/ContentGeneration.tsx): 승인된 스타일 재사용, 범위 선택·비용 확인·동일 요청 확인·이력 및 기존 select/review와 무료 배치 연결. 새 production 의존성/서비스 없음.
- [0017](../../migrations/0017_phase5_individual_regeneration.sql): 기존 단일 active index가 내용 검수 대기의 full job까지 실행 중으로 잡아 부분 생성을 차단했다. index 조건과 새 insert/update guard로 **full v3의 running/content_review + 같은 설교/퀴즈의 v2 summary/child/adult 하나**만 공존하게 한다. full의 열린 provider/command가 없어야 한다. 다른 full/legacy/부분 작업 동시 실행과 부분 작업 실행 중 full의 다음 단계/완료 전환은 차단한다. 기존 표/행/trigger를 재작성하지 않고 index 하나의 조건만 변경하며 새 trigger 두 개를 추가한다. Drizzle schema/SQL/snapshot/journal을 생성·검토했다. 원격 적용 없음.
