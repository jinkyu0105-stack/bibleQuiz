## 남은 연결 — 새 제품 결정 아님

1. **다음 독립 작업 P5-65: 관리자 새 설교 등록·미발행 작업 선택·발행 전 메타데이터 저장.** 기존 metadata 저장소·성경 파서·입력 저장을 재사용해 관리자가 DB/설교 ID를 직접 다루지 않고 현재 생성 흐름에 진입하도록 연결한다. 사용자에게 미연결 근거와 다음 번호 필요성을 먼저 설명했다. 이번에는 구현하지 않는다.
2. 공개 자막 자동 취득과 URL metadata/설교일 후보/중복 영상 안내는 현재 관리자 진입점에서 미연결이다. P5-65 시작 시 등록의 로컬 필수 경계와 구분한다. 합성 provider로 연결을 검증할 수 있으나 실제 YouTube/AI 호출이나 운영 채택을 승인한 것이 아니다.
3. [관리자 검수 명세](../spec/generation.md#115-관리자-ai-검수-화면--2026-08-17-갱신)와 현재 UI 차이: 의도 확정에 필수 검토 체크박스와 별도 재개 버튼이 남아 있다. 근거는 인용문을 펼치지만 영상 시각/원문 위치 이동·근거 교체·항목 추가/삭제·자동 저장·품질 평가/메모는 연결되지 않았다. 실제 기능은 명시 저장/사람 확정이며 이것을 명세 전부 완료로 쓰지 않는다. 명시 재개를 한 확인 동작으로 묶을 때도 자동 유료 재호출 금지를 유지해야 한다.
4. 비용 원장은 보존되고 현재 화면에 달력 주간/현재 작업 비용, 발행 확인에 퀴즈 전체 비용이 표시된다. 명세의 퀴즈 단위 고정 비용 표시와 호출/모델/token/가격표 상세 drawer는 미연결이다. 달력 주간 값과 퀴즈 총계를 같은 것으로 취급하지 않는다.
5. 출력 미리보기/파일은 Phase 6, 실제 반응형·접근성 최종 검수는 Phase 7B, 실제 AI 품질·Preview/Production 운영·Cron/백업은 별도 경계다. 생성·정리 기본 비활성을 유지했다. 후속 번호를 미리 늘리지 않는다.

명세의 요구를 현재 코드 수준으로 낮추거나 검사만으로 운영 승인을 만들지 않는다. 상세 요구는 그대로 유지하고 [현재 명세 안내](../spec/generation.md#p5-64-통합-검수의-현재-경계)에서 이 점검을 연결한다.

## 수정과 검사

- 제품 코드: 관리자 입력 안내 3곳만 정정. 발행 잠김, AI 교정 미연결이라는 오래된 설명, 입력 이력을 metadata 이력으로 표현하던 문구를 수정했다. 승인된 배치·스타일·자산은 그대로다.
- 새 Worker 통합 **1건 통과**. `/tmp/p5-64-targeted-v4.log`. 처음 세 실행은 테스트의 사용량 컬럼(`generation_job_id`), 제출 UUID v7, 합성 secret hex 형식 오류로 실패했다. 공개 기간 필드와 제출 성공 기대값도 기존 계약에 맞췄다. 제품 계약/schema를 완화하지 않았다.
- 실제 Chromium/모바일 Chromium **12개 케이스 최종 통과**. 최초 실행은 10통과/2실패(`/tmp/p5-64-e2e.log`), 실패한 생성 검수 2건은 수정 후 통과(`/tmp/p5-64-e2e-repair.log`). 기존 E2E 합성 응답이 선택/편집/확정 때 필수 `rootAnalysisId`를 누락하고 있었으며 실제 API는 이를 제공한다. 합성 응답을 수정하고 응답 schema 검증을 넣었다. 목록 조회 결과가 아니며 실제 기기·원격 검수도 아니다.
- 출시 기준의 과거 항목별 교정 문구를 이미 확정된 D-029 문서형 교정 계약으로 정합화했다. 새 정책 결정은 없다.
- **`pnpm check` exit 0**: 단위 **30파일/271건**, Worker **72파일/1,967건**, 실제 로컬 Workflow **1파일/3건**, lock/Cloudflare 설정·Drizzle·임시 Preview fixture·lint·typecheck·build 통과. `/tmp/p5-64-check.log`. 의도적 제약 위반 검사의 workerd stderr와 최종 suite 성공을 구별한다. 미해결 필수 검사 실패 없음.
- 최종 `git diff --check`·문서 로컬 링크·보존 SHA 대조를 완료했다. 완료한 P5-64와 별개로 Phase 5의 남은 연결/운영 게이트를 유지한다.
