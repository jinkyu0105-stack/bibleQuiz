## 변경

- AdminNavigation에 ‘관리 공간’을 복원했다. 기존 Noto Serif KR 600, 24px와 절제된 명암을 사용해 글자 표면감을 준다. 제목 뒤 여백 12px, 기존 유리 메뉴·모바일 접기 유지. 밤 명암과 강제 색상 단색 대안을 확인했다.
- ThemeControl의 잔디는 거친 세 줄을 그대로 재현하는 방식에서, 바닥선 위 세 풀잎의 끝·곡률·비례·밑동을 다듬는 방식으로 수정했다. 기존 스케치의 가운데 높은 구도는 유지한다. 작은 빼기 배지, 사진 복귀, 저장, aria 상태, 광원은 보존했다. 불필요해진 켜짐 배지 CSS를 제거했다.
- 디자인 스킬은 기존 디자인을 보존하는 타이포·간격·형태 검토에만 적용했다. 관리자 전체를 마케팅 화면으로 바꾸지 않았으며 기존 유리·명조·아이콘 체계를 따른다. 사용자 스케치 요청에 맞춘 기존 SVG의 보정으로 새 라이브러리를 추가하지 않았다. 동작·밀도는 유지하고 새 모션은 넣지 않았다.
- 기존 시안을 재생성하지 않고 이미지 데이터로 다시 첨부했다. `http://localhost:5173/docs/design/phase-9/manual-reader/reference.png`가 HTTP 200 / image/png / 1586×992로 응답하고 브라우저에서 디코딩되는 것을 확인했다. Windows 앱의 브라우저 열기는 queued 응답이므로 사용자 화면에서 보였다고 단정하지 않는다. 원본 위치는 그대로 보존한다. 4189는 응답하지 않았고 이번 범위에서 새 서버를 만들지 않았다.
- 반복된 WSL 이미지 표시 문제를 방지하도록 AGENTS에 이미지 자체 첨부/검증된 HTTP 주소 규칙을 추가했다. 매뉴얼 시안 README, 디자인 정본, D-047 후속 정정, STATUS/HANDOFF를 갱신했다.
