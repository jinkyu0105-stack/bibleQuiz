# P8-02 승인된 AI 연결 묶음

2026-10-03. 공개 접속·관리자 보호·자동 백업·7일 초안 정리는 적용과 검수를 마쳤다. 사용자는 아래 연결 묶음에 “알겠습니다. 다음 작업 승인합니다. 재개하세요”로 추가 승인했다. 기존 키의 비공개 콘텐츠 서버 Secret 전달·설정·필수 검사·배포까지 완료했다.

승인할 범위는 **기존에 보관한 키를 비공개 콘텐츠 서버에 연결하고, 관리자 버튼으로 AI 작업을 시작할 수 있도록 설정한 뒤 검사·배포하는 것**이다. 이후 운영자가 생성 버튼을 누르면 별도 AI API 비용이 발생할 수 있다. 이번 작업에서 새 유료 생성 시험은 하지 않는다.

- 앱: `AI_GENERATION_ENABLED`, `CONTENT_FINAL_CHECK_WORKFLOW_ENABLED`를 켠다.
- 비공개 콘텐츠 서버: `AI_GENERATION_ENABLED`, `AI_RESPONSE_ARCHIVE_ENABLED`를 켜고 기존 `OPENAI_API_KEY`를 서버 Secret으로 전달한다. 키는 표준입력으로 전달하며 새 로컬 사본을 남기지 않는다. 앱·백업 서버·브라우저에는 전달하지 않는다.
- 기존 모델 `gpt-5.6-terra`·추론 high·기존 결과/비용을 유지한다. 새 AI 생성 호출·유료 플랜 전환·구매·main push·Production 데이터 복원은 제외한다.

기존 키의 모델 정보 조회만 HTTP 200으로 확인했다. AI 생성 요청은 0회다. 관련 검사·lint/typecheck·pnpm check·Production 빌드/배포·기존 자료와 보호 설정 보존을 확인하고 STATUS/HANDOFF를 갱신했다. 실제 유료 생성 검수는 실행하지 않은 상태로 구분한다.

자동 승인 검토가 처음 시도한 AI 설정 켜기와 키 사본 생성을 거절했다. 이유는 기존 ‘새 AI·유료 호출 제외’ 범위를 넘는 향후 비용과 키 확산 위험이었다. 거절된 명령은 시작되지 않았고 설정·키는 변경되지 않았다. 이 승인안은 자동 검토를 우회하지 않으며 이후 위 명시 승인을 받았으며 새 사본 없는 표준입력 전달 방식으로 승인된 범위를 실행한다.
