# P8-02 브라우저 자막 자동 취득 실증

2026-10-03 사용자 요청: 프로그램이 실제 브라우저에서 ‘스크립트 표시’를 열고 읽어 저장하는지 확인한다. 사용자가 직접 복사해야 한다는 앞선 해석과 안내를 철회한다. 자동화 목표는 유지하며 별도 작업 번호를 만들지 않는다.

## 실제 결과

기존 Playwright 1.62.1과 WSL의 별도 headless Chromium에서 사용자 지정 영상의 YouTube 페이지를 열고 실제 ‘더보기’ → ‘스크립트 표시’ 버튼을 클릭했다. Google 로그인, 사용자 Chrome/오른쪽 패널 조작, 쿠키 가져오기, 프록시, 유료 AI 호출 없이 화면 자막 취득에 성공했다.

표시된 269구간·12,792자를 JSON과 UTF-8 텍스트로 저장했다. 첫 시각0:00, 마지막31:46이다. DOM에서 읽은 모든 행과 파일의 개수·텍스트 일치, SHA-256, 시간 순서, 빈 텍스트 없음 검사를 통과했다. 앞선 서버 미리보기의768구간/12,993자는 보관된 원문이 없어 정확한 내용 비교를 할 수 없으며 같은 분할/텍스트라고 단정하지 않는다. 이번 값은 현재 브라우저에 표시된 스크립트 기준이다.

첫 실행은 화면을 여는 데 성공했으나 구형 renderer 선택자로 저장하지 못했다. 두 번째 실행은 접근성 이름의 시간 선택자 대기에서 실패했다. 세 번째는 관측한 실제 DOM 시간 행을 기준으로 전체 저장을 완료했다. 총 브라우저 탐색3회다. 이제 원본이 저장됐으므로 재검사·세션 전환을 이유로 다시 취득하지 않는다.

## 보존 위치와 적용 범위

원본/화면/실행 스크립트/검증은 Git 제외 디렉터리 `.wrangler/releases/p8-02-browser-transcript-probe`(0700, 파일0600)에 보존했다. `transcript-private.json`, `transcript-private.txt`, `visible-rows-private.json`, `transcript-screen.png`, `capture-browser.cjs`, `proof.json`을 재사용한다. 실제 영상/자막 전문을 Git에 넣지 않는다.

이는 로컬 브라우저 자동 취득 성공이다. Cloudflare에서 브라우저를 실행한 결과나 관리자 버튼→자동 원본 저장 연결 완료로 확대하지 않는다. 이번에는 운영 DB/Secret/배포/AI를 변경하지 않았다. 기존 앱 소스657개 해시가 직전 검사/배포와 같고 기존 미커밋 변경·0000~0038·키·유료 결과·폰트/출력 패치를 보존했다. 제품 코드가 바뀌지 않아 전체 pnpm check나 완료한 입력/PDF 검사를 반복하지 않았다. 문서 diff와 링크·파일 검증을 수행한다.

## 다음 P8-02

확보한 원본을 재사용해 관리자 입력으로 연결할 경로와 반복 운영할 브라우저의 실행 위치를 정한다. 기존 입력 저장/사람 확정/AI 파이프라인을 재사용하고 자막을 AI로 만들어 보완하지 않는다. 사용자의 직접 복사를 기본 해법으로 넘기지 않는다. 현재 WSL 브라우저 실증은 새 상시 서버·새 유료 서비스·사용자 로그인 자동화 도입 승인이 아니다. 실행 위치별 비용/사용자 PC 의존성과 필요한 변경을 구분해 검토 가능한 연결안을 만든다. 기존 승인된 사용자 AI 검수와 agent 새 유료 호출 금지는 유지한다.
