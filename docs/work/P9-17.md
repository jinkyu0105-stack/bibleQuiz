# P9-17 내부 화면의 정보 구조·가독성 재설계

## 범위와 현재 상태

**로컬 구현·검사 완료.** 시작 main 33f5737, clean. 메인/하늘·유리 재질·실제 처리 기능·데이터를 보존하고 관리자 및 비메인 공개 화면의 정보 계층을 재설계한다. 새 의존성, 실제 자료/AI 실행, 원격 DB 변경, push/배포는 포함하지 않는다.

## 재현된 문제와 구현 방향

- sky.css가 제목의 명조체를 inherit로 덮고 본문 400 폰트에 굵기 합성을 막아 강조가 사라졌다. 비메인 화면에만 실제 Serif 600 제목과 본문 굵기·크기 계층을 적용한다.
- 주간 운영은 퀴즈·비용·안내의 우선순위가 섞이고 동일 자료를 중복 표시한다. 퀴즈 관리 목록, 명확한 상태/행동, 별도 문의함과 비용 화면으로 정리한다.
- 설명은 필요할 때 펼치는 도움말로 옮기고 각 항목은 레코드 단위로 구분한다.
- 홈은 자동 대표 선택을 지원하지만 관리자는 수동 지정만 표시한다. 기존 공개 선택 규칙을 공유해 실제 홈 퀴즈를 정확히 표시한다.

## 구현과 검수 진입점

- `src/styles/interior.css`: 메인을 제외한 콘텐츠의 명조 제목, 본문·라벨·버튼 계층. 추가 라이브러리/글꼴 다운로드 없음.
- `AdminNavigation` / `Dashboard`: 3개 주 메뉴와 접힌 도구/설정, 실제 홈 퀴즈, 상태별 검색 목록. 기존 하늘 유리를 재사용한다.
- `AdminGuide` / `AdminRecord`: 짧은 도구명·접힌 도움말, 문의/참여 레코드의 공통 읽기 순서. native details로 입력과 키보드를 보존한다.
- `Workspace`, `Policy`, `OperationsPanel`, `Manual`: 기능별 접기. `ContentGeneration`은 실제 내용을 읽은 뒤 검수 완료를 누르는 순서로 바꾸고 겹친 편집 테두리를 줄였다.
- 공개 풀이/지난 퀴즈/문의: 같은 서체 계층, 간결한 상태·발행 정보, 동등한 목록 크기, 정리된 문의 양식. 메인 축약 목록과 배경·유리·잔디는 그대로다.
- `home-quiz-selection.ts`: 공개 API의 기존 대표 선택 기준을 공통화한다. 관리자는 공개 가능한 후보를 읽어 `homeQuiz`를 반환한다. 수동 대표 지정과 자동 선택을 구별하며 DB 쓰기 없음.
