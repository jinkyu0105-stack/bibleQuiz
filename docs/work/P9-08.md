## 현재 구현

- `SkyScene`의 ground를 grass/photo로 복귀한다. 이전 none 경로는 제거하며 기존 사진/산/잔디 수/바람/영상은 그대로 사용한다. 풀잎 버튼 글자 제거, 접근성 이름 유지, 선명하게/풀잎도 공통 포인터 광원 연결.
- `PageDock`은 홈 SVG/퀴즈/문의 경로, 푸터 왼쪽은 다사랑교회 성경퀴즈다.
- `useHomeSectionScroll`: 메인 전용, rAF timestamp의 가감속으로 한 화면 약1.2초/거리별0.9~1.6초. 작은 휠 의도/관성 연속 건너뛰기 방지, 긴 섹션/중첩 스크롤/확대 휠 보존, 사용자 입력/이탈/감소에서 취소. 모바일 터치는 native snap, 처음 해시/뒤로 가기는 Router 복원이다. 같은 페이지 앵커는 클릭 전 위치에서 Router 복원 뒤 paint 전에 출발점을 되돌려 이동한다.
- `GlassButton`: native 버튼 props/ref만 전달하는 가벼운 재사용 컴포넌트. 공통 CSS 반사/테두리와0.6px blur,10px 모서리. 버튼별 SVG 필터/관찰자/상시 JS loop 없음. 관리자 실행 버튼 전체에 적용하고 이미 공통 선택 유리인 검수 탭과6단계는 유지한다. 첫 작업 이동 링크는 같은 CSS의 `GlassButtonLink`로 맞춘다. 중첩 패널의 SVG 굴절로 회색화되던 캡처를 보고 이 링크도 개별 필터 없는 같은 재질로 통일했다.
- 관리자 사이드바의 예전 하늘색 hover와 주간 다음 행동의 과거 불투명 채움을 제거한다. 실제 폼/저장/확인/API에는 변경이 없다.

현재 동작은 [디자인 명세](../spec/design.md#관리자-실행-버튼--p9-08), 재사용 방법은 [React UI](../../src/components/README.md)를 따른다.

## 근거·선택하지 않은 접근

Context7 `/mdn/content`에서 WheelEvent deltaMode/passive:false, rAF timestamp를 조회했다. 설치 React19.2.8/Router7.18.2의 기존 복원 순서는 코드와 이전 공식 조회를 대조했다. [MDN scroll-behavior](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scroll-behavior)는 기본 smooth의 시간/곡선을 브라우저가 정한다고 설명한다. native smooth만으로 속도를 조절하거나 새 스크롤 패키지를 넣는 접근은 사용하지 않았다. [React 재사용 컴포넌트](https://react.dev/learn/your-first-component), [web.dev 애니메이션 비용](https://web.dev/articles/animations-guide)을 확인했다. 공유 코드만으로 수십 개 렌더 비용이 없어지거나 기기 성능이 보장된다고 설명하지 않는다.
