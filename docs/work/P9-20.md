# P9-20 — 운영 매뉴얼 시안 적용·사이드바·잔디 스케치

2026-10-13. 시작 경로 `/home/onegem/work/bibleQuiz`, Git `main` / `b1a5d8d`, clean. 사용자 요청 범위는 운영 매뉴얼 콘텐츠 재설계, 강제 줄바꿈 보정, ‘관리 공간’ 제거와 간격 축소, 첨부 스케치의 잔디 아이콘이다. 기존 데이터·인증·실행 기능·하늘과 외부 유리 재질을 보존한다. push·배포는 포함하지 않는다.

## 구현

- 명시 요청한 `imagegen-frontend-web` 스킬로 가로형 매뉴얼 패널 시안 한 장을 생성했다. [참고 이미지와 방향](../design/phase-9/manual-reader/README.md). 그림은 디자인 참고 자료이며 앱에서 로드하지 않는다.
- `ManualReader.tsx` / `manual-reader.module.css`: 왼쪽 목차, 선택한 주제 하나의 본문, 순서에 따른 다음 안내. 기본은 퀴즈 만들기이고, 설정·서비스 사전은 목차에서 펼친다. 760px 이하에서는 주제 선택 메뉴가 된다. 선택 시 본문 제목으로 초점을 옮긴다.
- `ManualText.tsx`의 `ManualBody`를 공용으로 재사용하고 섹션 파서는 `manual-sections.ts`에 둔다. Markdown HTML은 실행하지 않고 인라인 코드·강조·목록·주의 안내를 유지한다. 문장 내부 개행은 공백으로 읽으며 짧은 한국어 서술부는 한 덩어리로 표시한다. 향후 계획 문서는 기존 펼침 구조를 유지한다.
- `docs/operations-manual.md`의 제작 순서를 자료 등록 / 내용 확인 / 검토 후 발행으로 묶고 생성 사본을 동기화했다. 기존 14개 문서 주제와 10개 서비스 설명·요금 기록을 유지했다. 과거 상자 전용 미사용 스타일을 제거했다.
- 관리자 사이드바에서 ‘관리 공간’을 지우고 사이트 이름 뒤 여백과 중첩 nav의 불필요한 위아래 padding을 줄였다. 원래 경로·유리 hover·모바일 접기를 유지했다.
- `ThemeControl.tsx`는 사용자가 그린 바닥선 하나와 세 가닥 선을 SVG로 옮겼다. 가운데 선이 가장 높고, 켜짐 체크 배지를 없앴다. 꺼짐의 작은 빼기 배지와 사진 전환·저장·hover는 유지했다.

## 검사와 보정

- 관리자 관련 Chromium PC / 모바일 / Firefox 18건 최초 실행: 16통과, 2실패. 목차와 ‘다음 안내’에 동일한 OpenAI API 이름이 생긴 것을 검사 선택자가 구별하지 못했다. 목차 안의 버튼을 지정하도록 수정했다.
- 해당 매뉴얼 검사와 잔디 전환·광원 검사의 세 환경 재검사 9건 전부 통과. 최초 통과와 합해 **고유 시나리오 24건** 통과 근거가 있다. 사이드바 이름 제거/여백, 입력 보존, 도움말 이동, 실패 재조회, HTML 비실행, 짧은 서술부 묶음, 주제 선택/초점 이동을 포함한다.
- 실제 5173에서 1440 / 1024 / 768 / 390 / 320px, 낮·밤 본문과 서비스 사전을 캡처했다. 첫 캡처의 목차가 공통 `nav { display:flex }` 때문에 좁아지는 문제는 scoped block/padding으로 고쳤고 회귀 검사에 추가했다.
- 320px에서 모든 24주제의 선택·본문·초점·가로 넘침을 확인했다. ‘다음 안내’가 목차 순서를 따르는지, 강제 색상 키보드와 네 시간대의 잔디 켜짐/꺼짐을 확인했다. 임시 시각 검사에서 노을의 값을 sunset으로 잘못 쓴 부분은 실제 dusk로 수정했다. 최종 가로 넘침과 pageerror는 0건이다.
- 최종 lint·typecheck·build, 매뉴얼 사본 동기화, diff 검사 통과. 기존 fontkit 등 500KB 청크 경고는 남아 있다. Phase/배포 완료가 아니므로 전체 `pnpm check`는 반복하지 않았다. 실기기/GPU와 원격 인증 화면은 이번에 검사하지 않았다.

초기 파서의 비컴포넌트 export에 대한 Fast Refresh 린트 문제는 별도 parser 파일로 분리했다. 반복된 서비스 상자·채운 잔디 실루엣·문장 내부 강제 줄바꿈은 폐기했다. 검사 증거는 Git 제외 `.wrangler/releases/p9-20/`에 둔다. 디자인 기준은 D-047과 디자인 정본을 따른다.
