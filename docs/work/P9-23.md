- 관리자 소스의 메뉴·제목·버튼·설명·상태 문구를 문맥별로 읽었다. 제작 6단계, 발행 설정과 수정 도구, 참여/문의/필터/비용, 매뉴얼 14개 주제, 서비스 10종, 기능 검토 기록을 포함한다. 기존에 명확한 문구는 유지하고 ‘입력자료→설교 자료’, ‘발행 철회→발행 취소’, ‘관측 비용→예상 비용’처럼 같은 동작의 이름을 통일했다. 정규화·검수/확정·개인정보 삭제·문의 처리 완료는 실제 역할과 결과를 설명한다. 데이터·기술 식별자·가격 수치/확인일·보관/삭제 정책은 바꾸지 않는다.

## 한계와 보존

이모지의 모양은 기기의 시스템 글꼴에 따라 달라진다. WSL의 미설치 글꼴로 인한 빈 네모는 캡처에서만 이미 설치된 Windows 글꼴을 읽어 해결했고 앱에 글꼴을 배포하지 않는다. 새 화면 예시는 연습 자료이며 실제 운영 검증 증거가 아니다. 실기기·화면 읽기 프로그램·원격 인증/배포는 이번 검증 범위에 포함하지 않는다. Phase/배포 단위의 전체 필수 검사는 별도 경계에서 수행한다.

폐기한 접근: 문장마다 이모지를 기계적으로 붙이기, 사용자 데이터/기술 식별자 변환, 읽는 중 스크롤하면 무조건 말풍선 닫기, 실제 UI가 가능한 곳에 새 가상 시안 만들기, 개인정보가 있는 실제 기록을 공개 정적 이미지로 쓰기.

**현재 P9-23 로컬 완료 · 부모 관리자 이해 돕기 로컬 완료 · 다음 사용자 화면 확인/피드백 · 세션 유지 · 다음 추천 GPT-6-astra/max** — 시안과 실제 화면의 시각적 균형을 대조하는 후속 보정에 적합하다.
