### 실제 반영

- 관리자 소스의 메뉴·제목·버튼·설명·상태 문구를 문맥별로 읽었다. 제작 6단계, 발행 설정과 수정 도구, 참여/문의/필터/비용, 매뉴얼 14개 주제, 서비스 10종, 기능 검토 기록을 포함한다. 기존에 명확한 문구는 유지하고 ‘입력자료→설교 자료’, ‘발행 철회→발행 취소’, ‘관측 비용→예상 비용’처럼 같은 동작의 이름을 통일했다. 정규화·검수/확정·개인정보 삭제·문의 처리 완료는 실제 역할과 결과를 설명한다. 데이터·기술 식별자·가격 수치/확인일·보관/삭제 정책은 바꾸지 않는다.
- 사이트 소개의 문제는 문자 `<br>`가 아니라 문장 끝 여러 단어를 `nowrap`으로 묶던 기존 `ManualText` 처리였다. 이를 제거하고 설명을 ‘회원가입 없이 참여하고, 빈칸이 있어도 제출할 수 있습니다.’로 다듬었다. 관리자 한글 단어와 도움말 용어의 조사·어미만 유지하며 문장 전체를 묶지 않는다. 나머지 `<br>`는 날짜/마감, 답/단서, 처리 일시/사유처럼 별개 필드 구분임을 확인했다. 운영 매뉴얼과 기능 검토 기록을 고친 뒤 실제 Worker 사본을 다시 생성했다.
