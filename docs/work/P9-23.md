## 구현

- `src/config/admin-help.ts`의 쉬운 설명을 `AdminHelp`로 연결했다. 관리자 주요 제목·제작 단계·작업 안내와 매뉴얼에 장식 이모지를 적용하고, 29개 개념을 작업별 용어 줄 및 매뉴얼 본문에서 설명한다. 텍스트 이름과 사용자/설교 입력은 유지한다.
- 말풍선은 native Popover의 최상위 표시를 사용해 유리 패널에 잘리지 않는다. 요소 위를 우선하고 위쪽 공간이 부족할 때만 아래로 표시한다. 호버/포인터 이동·초점/터치·Escape/바깥 클릭, 스크롤 위치 보정과 화면 경계를 다룬다. 위험 안내를 제거하거나 저장/발행 동작으로 연결하지 않는다.
- `AdminScreenshots`와 설정으로 실제 앱 캡처 8종을 제공한다. 매뉴얼 주제 2/3/6/7/9/10/11 및 관련 관리자 작업에서 접근한다. 확대창은 실제 크기 보기/스크롤·키보드 순환·닫기/초점 복귀를 지원한다. [자산 출처·크기·재현](../design/phase-9/admin-guide/README.md).
- 공통 `AdminGuide`와 모든 관리자 영역(퀴즈 목록·주간 제작·발행 설정·도구·참여·문의·필터·비용·매뉴얼)을 연결했다. 기존 선 아이콘, 시간대 색상, 고딕 ‘관리 공간’, 직선 잔디, 실제 원문·입력·저장·검수·발행 정책을 보존한다.
- 외부 문서는 Context7의 React 19 ref/useId/DOM 수명 관리와 [Popover](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using), [tooltip 접근성](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/), [dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)를 확인했다. 프로젝트 React19.2.8/Playwright1.62.1을 사용한다.

## 한계와 보존

이모지의 모양은 기기의 시스템 글꼴에 따라 달라진다. WSL의 미설치 글꼴로 인한 빈 네모는 캡처에서만 이미 설치된 Windows 글꼴을 읽어 해결했고 앱에 글꼴을 배포하지 않는다. 새 화면 예시는 연습 자료이며 실제 운영 검증 증거가 아니다. 실기기·화면 읽기 프로그램·원격 인증/배포는 이번 검증 범위에 포함하지 않는다. Phase/배포 단위의 전체 필수 검사는 별도 경계에서 수행한다.

폐기한 접근: 문장마다 이모지를 기계적으로 붙이기, 사용자 데이터/기술 식별자 변환, 읽는 중 스크롤하면 무조건 말풍선 닫기, 실제 UI가 가능한 곳에 새 가상 시안 만들기, 개인정보가 있는 실제 기록을 공개 정적 이미지로 쓰기.
