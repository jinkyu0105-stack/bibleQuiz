## 사용자 의도와 범위

사용자는 관리자 화면의 설명·크기·간격·색과 위계가 산만하다고 반복 지적했다. 가장 최근 확정 범위는 다음과 같다.

1. 다섯 의미 색상 모두 새벽·낮·노을·밤 버전을 만들고 소개한다. 자주색만 바꾸는 요청이 아니다.
2. ‘관리 공간’을 굵은 고딕으로 표시한다.
3. 잔디는 사용자가 그린 수평 바닥선과 세 수직선을 **직선으로 정교화**한다. 곡선 풀잎으로 재해석하지 않는다.
4. 기존 매뉴얼 시안처럼 콜아웃과 콘텐츠를 실제로 꾸민다. 채워진 단계 번호, 굵은 제목, 목차/서비스 아이콘과 선택 강조를 포함한다.
5. 새 사이드바 시안처럼 실제 관리자 좌측 메뉴를 꾸민다. 시간대별 역할 색을 적용한다.

메인·기존 자료/연습 DB·메뉴 기능을 보존한다. 새 의존성·원격 자료 변경·유료 AI·push·Preview/Production 배포는 포함하지 않는다. 이미 만든 시안은 재사용한다.
