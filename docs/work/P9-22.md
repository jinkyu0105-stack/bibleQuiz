## 완료한 사용자 결과

기존 [매뉴얼 시안](../design/phase-9/manual-reader/reference.png)과 [사이드바 시안](../design/phase-9/admin-sidebar/reference.png)을 직접 열고, 변경 전후 실제 화면을 캡처해 대조했다. 시안 이미지 재생성·의존성 추가 없이 구현했다.

- 매뉴얼: 느낌표 아이콘·얇은 전체 테두리·여백이 있는 콜아웃, 선명한 채움 번호와 연결선, 굵은 고딕 단계 제목, 목차·서비스 선 아이콘과 활성 배경/왼쪽 표시를 적용했다. 서비스 제목에 이동한 키보드 초점 테두리와 부제 간격도 분리했다.
- 사이드바: 220px 기존 폭 안에 ‘퀴즈 운영’ 그룹 제목을 추가하고 ‘도구와 설정’과 같은 13px/700 실행 색상으로 맞췄다. 20px 아이콘, 행과 그룹 간격, 구분선, 활성 배경과 왼쪽 3px 표시를 적용했다. 제목은 굵은 고딕 단색이다. 다른 메뉴의 유리 호버가 실제 활성 표시를 지우지 않는다.
- 색상: 기존 다섯 의미 역할 × 네 시간대의 글자/받침을 그대로 사용한다. [색상 비교](../design/phase-9/admin-sidebar/palette.html)와 [정본](../spec/design.md#p9-19-관리자-의미-색상과-읽기-위계--2026-10-13)에 전체 값을 둔다.
- 보존: 14개 문서 주제·10개 서비스, 기존 실제 문장, 다음 안내, 모바일 주제 선택/초점 이동, 관리자 메뉴 접기/경로, 미저장 편집 보호, 감소 모션·투명도·강제 색상, 메인·하늘·직선 잔디, 기존 자료/키/로컬 연습 DB.

## 구현 진입점

- `src/components/AdminIcon.tsx`: 기존 관리자 선 아이콘을 목차·서비스·콜아웃과 공유. 장식 SVG는 `aria-hidden`이며 실제 이름은 옆의 글자로 제공한다.
- `src/features/admin-weekly/AdminNavigation.tsx`, `admin-navigation.module.css`: 그룹·아이콘·선택 배경/표시·여백과 반응형. 공통 유리 엔진은 변경하지 않았다.
- `src/features/admin-operations/ManualReader.tsx`, `manual-reader.module.css`: 목차/서비스 아이콘·단계/본문 위계·선택 표시. `ManualText.tsx`, `operations.module.css`: 안전한 텍스트 콜아웃과 목록 접근성.

자세한 수치와 제품 동작은 [디자인 정본](../spec/design.md#p9-22-시간대-색상과-승인-시안의-실제-적용)을 따른다. 일반 본문의 자연스러운 줄바꿈과 안전한 텍스트 렌더링을 보존했고 강제 개행을 추가하지 않았다.

## 최종 검사와 증거

- `pnpm run lint`, `pnpm run typecheck`, `pnpm run build`: 모두 exit 0. 기존 fontkit 포함 500kB 초과 번들 경고는 유지한다.
- 관련 E2E **15건 통과 / 실패·재시도 0** (Chromium PC·Pixel 7 모바일·Firefox). 매뉴얼 읽기 실패/재시도·HTML 비실행·서비스/초점, 사이드바 실제 경로/호버/접기, 미저장 편집의 이동 차단, 320px 키보드 탐색을 확인했다.
- 명령: `pnpm test:e2e tests/e2e/admin-glass.spec.ts tests/e2e/admin-operations.spec.ts tests/e2e/admin-weekly.spec.ts --project=chromium --project=mobile-chromium --project=firefox --grep 'admin menus|manual|weekly header|autosave conflict' --workers=2 --reporter=line`.
- 실제 5173에서 새벽·낮·노을·밤의 1440px PC와 390px/320px 모바일을 캡처했다. 번호/제목/콜아웃/목차/선택 표시와 자연스러운 줄바꿈을 시안과 직접 비교했다. 24개 주제/서비스 이동, 다음 안내, 초점과 제목 노출, 네 시간대 가로 넘침 없음, pageerror 0·API 쓰기 0을 확인했다. 역할 글자/받침 20쌍과 번호 4쌍 대비 **5.20~8.40:1**. 감소 모션·투명도 줄이기·강제 색상도 확인했다.
- 시안 PNG 2개와 색상 비교 최종 URL은 HTTP 200이며 PNG 디코딩을 확인했다. Windows 앱의 사용자 표시 확인과 HTTP/자동 브라우저 검사는 구별한다.
- 증거는 Git 제외 `.wrangler/releases/p9-22/`의 `verify-ui.mjs`, `implemented-visual.json`, `implemented-*.png`, `e2e-final.log`, `build-implementation.log`다. 이전 부분 검사 증거는 덮어쓰지 않고 보존했다.
- 최종 문서 `git diff --check` 통과, 수정 문서9개의 로컬 파일/절 링크 누락0건을 확인했다. 이 작업은 Phase 전체/배포 완료가 아니므로 전체 `pnpm check`·전체 E2E·원격 Access/실기기 검사를 반복하지 않았다.

초기 E2E는 14통과·Chromium 호버1건 실패였다. 같은 코드의 단독 추적3회는 통과해 최초 실패를 확정 재현하지 못했다. 펼침 직후 유리 메뉴의 ResizeObserver/글꼴 측정이 호버 상태를 지우는 코드 경로를 확인했고, 검사에서 초기 측정 완료 후 호버하도록 동기화했다. 공통 엔진을 수정하거나 검사를 삭제하지 않았으며 최종15건은 모두 통과했다. 기존 주간 화면의 hash 이동 관련 router 경고는 최종 검사에도 관측됐지만 이동 차단 검증은 통과했다.
