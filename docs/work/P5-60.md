## 최초 작은 범위 — 편집 미리보기

- 기존 철회 revision과 현재 review_ready + paused·모든 variant withdrawn·전체 revision 제출 0건을 확인하고 영구 철회 snapshot만 읽는다. 초안이나 옛 generation ticket을 현재 편집본으로 사용하지 않는다.
- 기존 좌표에서 답·단서를 수정한 임시 결과를 만들고 두 난이도를 한글 정규화/길이·중복 답·배치 연결/교차·공개 격자/번호·채점 정합성으로 검사한다. 길이 변화는 재배치 필요, 교차 음절 충돌은 실패 사유로 반환하며 저장 자료를 자동 보정하지 않는다. 반대 난이도의 답/단서는 유지된다.
