# P9-07 메인 탐색과 서울 시간대

2026-10-10. P9-06 완료 소스863a84b 뒤 사용자가 요청한 메인 UI 보정이다. 실제 경로 `/home/onegem/work/bibleQuiz`, main clean·origin/main21b81de보다40커밋 앞선 상태에서 시작했다. 기존 자산/기능/미커밋 변경 보존, push/배포 제외. 추천 GPT-6.1-Sol/high.

## 사용자에게 보이는 변경

- 메인의 하단 유리 바를 `PageDock`으로 재사용한다. ‘바로가기’의 메인/풀이/관리자는 실제 경로로 이동한다. 푸터 왼쪽의 교회 문구 대신 ‘문의 · 삭제 요청’을 두고 개발/검수 설명은 제거한다. 이 설명은 localhost가 이 컴퓨터에서 시험하는 화면이며 운영 배포 완료와는 별개라는 뜻이었다.
- 중복 ‘화면 테마’ 선택을 제거한다. 네 시간대 버튼이 같은 배경/읽기 색상을 정하고 선명하게 아래 풀잎 버튼으로 잔디를 켜고 끈다. 잔디를 꺼도 산은 유지한다.
- 사용자가 서울 기준을 선택했다. 브라우저 날짜/좌표 계산으로 계절과 한국 표준시를 적용한다. 외부 호출·위치 권한·데이터 다운로드·새 의존성은 없다. 수동 선택의 추천 기간은 현재 탭이며 새로고침/페이지 이동에도 유지하고 독립된 새 탭은 자동으로 시작한다. 탭 복제/브라우저 세션 복원은 선택도 복원할 수 있다.
- 메인은 CSS scroll snap으로 섹션에 정렬하고 앵커는 부드럽게 이동한다. 이중 상단 여백을 제거해 ‘이번 주 퀴즈’ 도착 위치를 맞췄다. 긴 섹션/모바일은 내부 내용을 계속 읽을 수 있고 감소 모드에서는 snap/부드러운 이동을 해제한다.
- 두 번째 섹션의 WebGL 구름은 기존 독립 레이어의 느린 이동 속도를2배로 조정했다. 멈춤/감소/비활성 탭 정책을 유지하고 native 검토본의 기본 속도는 바꾸지 않는다.

제품 동작 정본은 [디자인 명세](../spec/design.md#메인-탐색과-서울-시간대--p9-07), 컴포넌트 사용법은 [React UI](../../src/components/README.md)다. 고정 평균 시간표나 날씨 API를 새로 도입하는 접근은 선택하지 않았다.

- `ThemeControl.tsx`, `PageDock.tsx`, `screens.tsx`: 시간 버튼/잔디 SVG/실제 경로/푸터. 같은 공통 유리 엔진을 재사용한다.

- `home-page.tsx`/`screens.tsx`: Router 해시 링크로 Firefox 스크롤 복원 충돌 해결, 기존 search 유지.

- 시간대 선택창을 사용하던17개 E2E는 같은 검증을 네 시간대 버튼으로 수행한다. 새로운 동작 검사는 `sky-app.spec.ts`, 태양 경계 검사는 `sky-time.test.ts`다.
