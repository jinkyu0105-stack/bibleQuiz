2026-10-08. **첫 화면 구름 밀도 복원 검수 대기**. 기존 숲·종이·색상 기준을 종료하고 Astra·Max로 처음부터 다시 만들라는 사용자 지시에 따른다. P9-06 대표 화면과 검토 동작을 만들었으며 사용자 시각 확인/보정이 남아 있다. 앱 연결과 배포는 완료로 보고하지 않는다. P9-04와 이전 Phase9 승인 범위 완료는 유지한다.

## 사용자에게 보이는 결과

[새 검토본](../design/phase-9/sky-v2/README.md): `http://localhost:4189/docs/design/phase-9/sky-v2/`. 기본 낮이며 오른쪽 네 버튼으로 새벽/낮/노을/밤을 비교한다. 스크롤하면 구름 사이를 지나 들판에 가까워진다. 하단 검토 메뉴에서 공개·풀이·관리자로 이동한다. Codex 브라우저 패널 열기를 요청했으며 도구 응답은 `queued`였다.

공개는 큰 한글 제목, 이번 주 두 난도 선택, 지난 퀴즈를 구성했다. 풀이는 모바일 전체 격자/단서/예시 한글 입력·이전/다음·초기화를, 관리자는 기존 운영 메뉴/6단계/요약과 두 난도 탭·편집 미리보기·검토 확인을 보여 준다. 실제 원문/설교/AI 결과 대신 명시한 예시만 쓴다. 예시 편집은 메모리 안에서만 유지하며 새로고침하면 초기화된다. 시안 범위 밖 관리 메뉴는 안내창이며 실제 작업을 실행하지 않는다.

최초 대표 이미지5개는 낮/밤/지면/풀이/관리자를 각각 가로 한 장씩 만들었다. 별도 투명 구름3종을 추가해 하나를 반복하는 모양을 보완했다. 이미지 안에 글자를 합성하지 않았으며 최종 한글/입력/버튼은 HTML이다. 최초 최적화 자산은1,316,918bytes(약1.26MiB), 원본8개는 생성 위치와 `.wrangler/design-references/p9-06-air/masters/`에 보존했다. 정확한 프롬프트·생성 파일·해시·용량은 [assets.json](../design/phase-9/sky-v2/assets.json)에 기록했다.

## 넓은 화면과 구름 보정 — 2026-10-08

사용자는2560px 화면에서 잔디 양끝이 분지처럼 꺼지고, 왼쪽 구름이 잘리고, 오른쪽에 앙상한 구름3개가 반복된다고 지적했다. 산/구름 해상도와 첫 화면의 분리된 흐름도 요청했다. 이어 **콘텐츠 최대 폭1440px 유지·배경만 보정**으로 확정했다. 일시 적용했던 폭 확장은 되돌렸으며 실제 `src/styles/index.css`와 검토본 레이아웃 CSS의 최종 diff는0이다. 퀴즈/단서/관리자 배치를 확대하지 않는다.

- 2560×1080에서 지형 mesh의 양끝이 카메라 안으로 드러나는 문제를 재현했다. OriginKit 지면과 풀잎의 x좌표에 같은 화면 비율 배율을 적용해 양끝까지 이어지게 했다. 풀잎 개수/바람/광원/마우스 계산은 유지한다. 구름과 잔디 drawing buffer는 최대3840×2160으로 제한한다.
- 내장 imagegen으로 풍성한 투명 구름5종을 새로 만들고10개 위치에 배치했다. 기존3종은 렌더링에서 제외하고 파일은 보존한다. 실제 원본은각1672×941이며4K가 아니다. 의미 있는 alpha가 원본 네 가장자리에 닿지 않는 것을 확인했고 shader의 얕은 가장자리 fade도 적용했다. 모바일960px/일반1672px로 나누고 창을 넓히면 자동으로 큰 파일로 교체한다. 표시 폭 최대1120CSSpx, DPR최대1.4로 과도한 확대를 피한다.
- 직전 넓은 화면 보정에서는 첫 화면의 고정 원경 사진을 약하게 남기고 독립 구름들의 깊이·위치·속도·약한 상하 이동으로 흐름을 만들었다. 이 첫 화면 구성은 아래 후속 사용자 지시에 따라 원래 밀도/수평 이동으로 대체했다. 오른쪽 아래 세 구름은 서로 다른 자산이다. 기존 공통 시계·하강 진행도·멈춤을 사용한다.
- 산은 동일한 실제 사진의3840×2160 WebP를 원본 CDN에서 받아1600px/3840px `srcset`으로 연결했다. AI 업스케일/원본 센서 해상도 검증으로 보고하지 않는다. 첫 캡처에서 산이 보이지 않던 문제는 비동기 이미지 표시 시점으로 확인했고, 위치를 변경하는 대신 디코딩 완료 후 표시하도록 보완했다. 기존1600px 사진과 모든 구름 원본/폰트는 보존한다.

새 구름은 일반 파일5개1,161,398bytes·모바일5개422,300bytes, 산4K1,012,784bytes다. 새 자산 합계2,596,482bytes이며 같은 화면이 두 구름 크기를 모두 요청하는 것은 아니다(작은 창→큰 창 전환 예외). 새 이미지 생성5회는 내장 도구이며 별도 API 키·유료 이미지 API·재추출·설교 AI 호출은 실행하지 않았다. 새 패키지/서비스도 없다. 원본·프롬프트·해시·실제 크기는 [assets.json](../design/phase-9/sky-v2/assets.json), Git 제외 작업 근거는 `.wrangler/design-references/p9-06-wide/`에 있다.

### GPT Image2.5와4K 문의
