# P5-67 — 근거 검수·품질 평가·사람 의도 확정

2026-09-24. 완료 — 로컬 구현·합성 검수·전체 필수 검사·상태 문서. 부모 Phase 5는 진행 중이며 P5-66 완료 상태와 기존 미커밋 변경을 유지한다.

## 연결한 동작

- 관리자 화면은 확정된 현재 입력 source와 생성 snapshot의 source/document ID·SHA·확정 event를 대조한다. 일치하면 근거 구절의 정확한 원문 위치를 열고 시간 구간의 초를 표시한다. 공개 영상 자막에서만 YouTube 시각 링크를 만든다. 관리자는 원문에서 구절을 직접 선택해 근거를 교체·추가·삭제한다. 요약의 마지막 근거는 교체해야 하며, 의도의 마지막 근거 삭제는 `근거 확인 필요`, 후보의 마지막 근거 삭제는 관리자 확인 내용 작성으로 이어진다. 의도 문구 수정은 이전 근거를 재확인 상태로 돌린다. 현재 선택본의 수정은 기존 불변 사람 edit 명령으로 새 revision에 저장하고 원본·옛 snapshot을 덮지 않는다.
- `sermon_content_quality_reviews`(0029)에 snapshot별 관리자 평가·다섯 의도 검토 항목·메모·수정 revision/관리자 digest/시각을 추가한다. 동일 요청은 재생하고 다른 요청은 다음 revision을 쌓는다. `수정 후 사용`은 실제 사람 edit에만 연결한다. 최근 `재생성 필요`면 같은 자료의 사람 확정/검수·의도 재개·최종 검사/발행을 막는다. 평가 저장 자체는 provider 호출을 만들지 않는다. 평가 시각·건수를 기존 7일 초안 활동/경합 기준에 포함하고 정리 뒤의 평가 삽입을 막는다.
- 첫 전체 생성의 의도 대기에서 `재생성 필요`를 선택하면 화면의 별도 새 초안 버튼이 이전 작업을 종료하고 새 전체 분석·비판을 요청한다. 기존 결과와 관측 비용은 남는다. 내용 검수 단계에서는 기존 범위별 재생성 동작을 사용한다. 새 결과는 자동 채택하지 않는다.
- 의도 확정의 필수 검토 체크박스와 별도 재개 버튼을 없앴다. 확인창의 `확정하고 다음 생성 시작`은 사람 확정을 먼저 저장하고 AI 연결이 켜진 경우에만 명시 재개 요청을 보낸다. AI 연결이 꺼졌으면 확정만 저장한다. 재개 실패/불확실 상태는 확인 후 다시 명시 동작이 필요하다. 요약/후보의 사람 검수는 기존 별도 확인을 유지한다.
- 관리자 Access·same-origin·private/no-store 경계를 재사용하고 품질 메모/비공개 원문을 공개 DTO에 넣지 않는다. 새 production 의존성·외부 서비스는 없다.
