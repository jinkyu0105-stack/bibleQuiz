## 10. 시각 디자인과 이미지 자산

### 10.1 공통 디자인 방향

- 교회 사이트답되 과도하게 장식적이거나 기성 템플릿처럼 보이지 않게 한다.
- 말씀에 집중하는 중후함, 넓은 여백, 절제된 기하학을 공통 축으로 삼는다.
- 실제 퀴즈·단서·폼은 거의 불투명한 단색 패널 위에 둔다.
- 배경 이미지 자체에는 글자, 성경 구절, 로고, 워터마크를 넣지 않는다.
- bible.com의 이미지를 복사·가공하지 않고 분위기만 참고한다.
- 주간 이미지보다 읽기와 입력이 우선이다.

### 10.2 장년용 이미지

- 짙은 숲, 구름, 바다, 산맥, 사막, 새벽빛, 빛과 그림자
- 사진적이거나 회화적이어도 되지만 사색적이고 진지한 톤
- 인물은 기본 제외
- 과장된 렌즈 플레어, 값싼 종교 스톡 이미지, 이미지 안의 십자가 남용을 피한다.

### 10.3 어린이용 이미지

- 어린이가 좋아할 따뜻하고 독창적인 기독교 일러스트
- 자연, 교회 공동체, 빛, 열린 성경, 등불, 비둘기 같은 친근한 상징
- 어린이가 등장할 수 있으나 특정 실존 인물처럼 보이지 않게 한다.
- 유아용 캐릭터 상품처럼 지나치게 가볍게 만들지 않는다.
- 예수님의 외모나 성경 사건을 교리적으로 민감하게 재현하는 이미지는 관리자·목회자 검수 없이 사용하지 않는다.

### 10.4 데스크톱·모바일 자산

난이도마다 같은 원본을 억지로 자르지 않고 구성 자체가 다른 두 이미지를 준비한다.

```text
어린이용 desktop landscape
어린이용 mobile portrait
장년용 desktop landscape
장년용 mobile portrait
```

권장 원본 비율:

- 데스크톱: 16:9 또는 3:2 가로
- 모바일: 4:5 또는 9:16 세로

원본 master를 보관하고 배포본은 AVIF, WebP, JPEG fallback으로 변환한다. `<picture>`, `srcset`, `sizes`로 화면에 맞는 파일만 내려보낸다.

AVIF와 WebP는 JPEG/PNG보다 같은 화질에서 용량을 줄이기 좋은 웹 이미지 형식이다. AVIF를 모르는 사용자가 별도로 다룰 필요는 없으며 빌드가 자동 생성한다. 모든 브라우저 대응을 위해 JPEG fallback을 남긴다.

### 10.5 스크림과 가독성

스크림(scrim)은 배경 이미지와 글자 사이에 놓는 반투명 어두운 막이다. 사진의 밝고 복잡한 부분 위에서도 흰 글자를 읽기 쉽게 만든다.

- 장년은 숲 전체 배경과 오른쪽 아래 어두운 읽기 패널, 어린이는 종이 정원 위 왼쪽 제목과 아래 가로 정보 띠를 별개 구조로 구현한다. 어린이 제목을 장년 패널의 위치만 바꾼 형태로 만들지 않는다.
- 이미지 위에 흰 헤더 텍스트를 직접 올리는 구성에서는 `rgba(8, 14, 24, 0.45~0.72)` 범위의 스크림을 둔다.
- 실제 값은 이미지별 대비 검사로 조정한다.
- 퀴즈 본문 패널은 스크림에 의존하지 않고 자체 불투명 표면을 가진다.
- 이미지가 없어도 단색 fallback으로 전체 기능이 정상 동작해야 한다.
- P9-02 재작업은 Phase7A 01/02 원본을 입력으로 배경 4종을 새로 제작해 `/images/garden-v2/`로 적용한다. 모바일은 별도로 생성한 세로 구도를 사용한다. 장년 왼쪽/어린이 오른쪽 바로가기 메뉴는 좁은 화면에서 상단 공통 메뉴로 보완한다. 제목·설교일·장절·공식 읽기 링크·풀이 버튼은 실제 HTML이며, 짧은 요약 소개와 별도로 AI 요약 전문·고지·발행일·고유 주소를 아래에 보존한다. 제목이 길어지면 화면 높이를 늘리고 내용을 자르지 않는다.
- 제목은 Noto Serif KR 600, 본문은 Noto Sans KR의 자체 호스팅 WOFF2를 사용한다. Google Fonts 공식 부분 글꼴의 `unicode-range` 구분으로 현재 필요한 글꼴만 받는다. 기존 출력 TTF와 fontkit 패치는 보존한다. 장년 풀이의 어두운 표면/밝은 칸, 어린이 풀이의 밝은 종이/잎색 테두리로 난도별 시각 구분을 유지한다.
- 공개 격자와 단서, 결과 비교·참여 현황, 지난 퀴즈의 이미지 목록, 관리자 왼쪽 메뉴·6단계·주 행동을 승인 시안의 배치 기준으로 구현한다. 시안에 없는 상태·권한·편집/복구·출력 기능은 삭제하지 않고 별도 상세 영역이나 모바일 재배치로 유지한다.

### 10.6 디자인 토큰 초안

테마의 기준 팔레트는 확정하고, 실제 컴포넌트 조합은 디자인 시안 단계에서 WCAG 2.2 AA 대비를 통과하도록 다듬는다. 원본 테마는 에디터용 색상 체계이므로 색 이름을 그대로 UI 역할로 기계적으로 옮기지 않는다.

라이트 모드 — Everforest Light Medium 기반:

```text
page          #FDF6E3
surface       #F4F0D9
surface-muted #EFEBD4
border        #BDC3AF
text          #5C6A72
accent-green  #8DA101
accent-aqua   #35A77C
focus-blue    #3A94C5
danger        #F85552
warning       #DFA000
```

다크 모드 — Gruvbox Dark Medium 기반:

```text
page          #282828
surface       #3C3836
surface-raised #504945
border        #665C54
text          #EBDBB2
text-muted    #A89984
accent-green  #B8BB26
accent-aqua   #8EC07C
focus-blue    #83A598
danger        #FB4934
warning       #FABD2F
```

- 위 accent 원색을 작은 글자의 전경색이나 버튼 배경으로 무조건 사용하지 않는다. 실제 foreground/background pair는 대비 검사 후 더 짙거나 밝은 파생 토큰을 사용한다.
- 라이트는 새하얀 종이 느낌보다 따뜻한 아이보리와 잎색을, 다크는 순수 검정보다 Gruvbox의 갈색 섞인 짙은 표면과 크림색 글자를 사용한다.
- 테마 전환은 색상 토큰만 바꾸며 정보 구조·간격·글자 크기·정오 기호는 바꾸지 않는다.
- 배경 사진 위 스크림은 각 테마의 page 계열을 섞어 이질적인 검정 막처럼 보이지 않게 하되, 텍스트 대비를 우선한다.
- 맞음·틀림·경고는 팔레트 색뿐 아니라 `✓`, `×`, 경고 기호와 테두리 모양으로도 구분한다.

- 서체: 제목 `Noto Serif KR` 계열, UI·격자 `Pretendard Variable` 또는 `Noto Sans KR`
- 어린이 강조색: 따뜻한 금색, 잎색, 하늘색 중 절제된 2색
- 장년 강조색: 황동, 이끼색, 깊은 남청 중 절제된 1~2색
- 정답: 색 + 체크 기호
- 오답: 색 + `×` 기호
- 기본 Top3의 금·은·동은 작은 면적에만 사용하고 N이 4 이상이면 4위부터 중립 순위 스타일을 쓴다.

주간 이미지 4종을 매주 새로 만들면 Git이 빠르게 커진다. 이미지 자산은 `asset catalog`에서 재사용 가능 여부를 기록하고, 설교 분위기에 맞는 기존 배경을 우선 돌려 쓸 수 있게 한다. 새 이미지는 원본과 최적화본 용량을 검토한 뒤 커밋한다.

축하 일러스트는 어린이·장년 공용 한 세트만 둔다. `celebration-screen.webp`와 같은 화면 최적화본과 `celebration-print.png`와 같은 투명 고해상도 인쇄본을 하나의 master에서 파생하고 모든 주차에서 재사용한다.


### 10.7 Air 계승 하늘 방향 — 2026-10-08

사용자는 [Air](https://air.inc/)·[Refero Air](https://styles.refero.design/style/d3289fe7-a85e-42d8-96b7-eb7faa62a104)를 참고한 공개/관리자 UI 전면 개편을 요청했다. 어두운 하늘만의 방향을 대체한다. 밝은/어두운 하늘 모두와 원본의 시간대 선택, **같은 하늘 속에서 구름을 지나 지면으로 내려오는 연속 공간**을 구현 방향으로 삼는다. 이전 Phase9 완료/P9-04 배포는 철회하지 않으며 새 개편과 구분한다.

- 시간대는 새벽·낮·노을·밤을 같은 구성에서 선택한다. 하늘·구름·지면의 빛과 UI 전경/표면을 함께 조정한다. 새 초기 자동 시간 정책은 별도로 확정하지 않았고 원본의 시계/sessionStorage 정책을 그대로 제품 결정으로 옮기지 않는다. 기존 system/light/dark 선택·브라우저 저장은 앱 적용 때 호환한다.
- 모든 주요 영역은 하나의 이어지는 하늘을 배경으로 공유한다. 구름의 시간에 따른 이동과 스크롤에 따른 높이/시점 변화는 분리한다. 섹션별 하늘 사진 교체나 정지 사진 한 장의 단순 이동만으로 연속 공간 완료를 판정하지 않는다.
- 공개 첫 화면·소개/아카이브에서는 하강감을 충분히 보여 준다. 풀이 격자/단서·결과·관리자 편집은 읽기와 한글 입력이 우선이며 콘텐츠 패널은 안정적으로 고정한다. 장년/어린이는 같은 하늘 세계를 공유하면서 분명한 난도 이름·절제된 강조와 이미지 구성으로 구분한다.
- 장식 canvas/이미지는 정답·본문·실제 입력 UI를 담지 않는다. 제목/설교일/장절/공식 읽기 링크·요약·고지·권한·제출·채점·삭제·인쇄·관리자 확정/발행 조건은 모두 보존한다. 생성 이미지에 성경 구절이나 다른 글자·로고를 합성하지 않는다.
- 원본의 색/여백/경계·움직임 원리를 참고하고 Air 코드·cloud.png·유리 로고·3D 모델·Control 폰트는 복사하지 않는다. 기존 무료 자체 호스팅 한글/출력 폰트와fontkit을 먼저 재사용한다. 새 production 의존성/서비스는 비용·대안과 사용자 결정을 거친다.
- 모션 감소 설정·명시적 멈춤·숨은 탭 중단과 이미지/canvas 실패 시 읽을 수 있는 단색 배경을 유지한다. 터치 시간대 선택은44px 이상과 현재 선택의 비색상 표식을 갖는다. 초기 용량·모바일 성능은 기존 관측보다 악화시키지 않도록 실제 화면 구현 뒤 측정한다. 검토본 성공을 최종 성능/대비 통과로 쓰지 않는다.

디자인 방향 → 움직임 검토본 → 공개 낮/밤·모바일 풀이·관리자 대표 시안 → 확인한 시안 기반 전체 UI/관련 검사 → GitHub 기반 Preview → 별도 요청 Production 순서다. 실제 탐색의 사실·코드 진입점·검토본 한계는 [P9-05](../work/P9-05.md)를 따른다. [독립 움직임 검토본](../design/phase-9/air-sky-study/index.html)은 앱 적용본이 아니다.

#### 참조와 한글 서체 적용 기준

Refero는 디자인 설명/값의 참고 자료이며 원본 Air의 전체 동작 명세가 아니다. 움직임은 실제 Air 관측을, UI 표면·간격·형태는 Refero의 DESIGN.md/CSS Variables를 기준으로 대표 시안에서 대조한다. 현재 독립 검토본은 전체 색상·타이포·간격·가이드라인 준수 완료가 아니다. 참조 경로·실제 차이·서체별 공식 근거는 [P9-05 참조/글꼴 확인](../work/P9-05.md#참조-경로적용-범위한글-글꼴-확인--2026-10-08)에 한 곳으로 둔다.

- 한글을 지원하지 않는 원본/추천 폰트를 이름만 CSS에 추가하지 않는다. 기존 한글 글꼴을 우선 재사용하며 한글 지원·획/폭·영문/숫자 조화·실제 내려받는 굵기·OS별 폴백을 함께 확인한 무료 대체를 적용한다. 원본 폰트명을 맞추기 위해 현재 한글 글꼴을 바꾸지 않는다.
- 본문/UI는 기존 Noto Sans KR을 우선한다. Inter 역할의 대체 비교는 한글을 지원하는 Pretendard가 후보이며 제목의 강한 굵기에도 비교할 수 있다. 장식 강조는 Nanum Pen Script가 후보이나 Control Cursive와 동일한 형태라고 단정하지 않는다. 후보 검토를 다운로드/설치/최종 채택으로 기록하지 않는다.
- 현재 자체 호스팅 파일은 Noto Sans KR 400과 Noto Serif KR 600이다. CSS가 500/900을 요청한다고 해당 실제 글꼴 파일을 확보한 것으로 쓰지 않는다. 최종 화면은 필요한 실제 굵기를 연결해 확인하며 검토본의 OS 폴백이나 합성 굵기로 타이포 완료를 판정하지 않는다. 기존 제목/출력 폰트와 fontkit은 보존한다.
- 영어용 초대형 제목·좁은 행간을 한글에 그대로 강제하지 않는다. 제목/본문의 위계와 읽기 편한 한글 줄바꿈을 우선한다. Refero와 다른 값은 한글·퍼즐 입력·시간대/접근성의 이유를 명시하고 대표 시안에서 확정한다. 사용자가 요청한 밝은/어두운 하늘과 연속 공간을 Refero의 dark 요약/일률적인 배경 규칙보다 우선한다.
