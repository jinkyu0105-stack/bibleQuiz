# P9-23 홈 효과와 로딩 검수

## 초기 로딩·반사 조절 — 현재 검토본

[실제 전후 비교 화면과 측정표](loading-review.html) · [측정 조건·각 회차·화면 검수 원자료](loading-metrics.json).

`loading-before-{1440,390}.png`는 aa422c4(앱 c677d93), `loading-after-{1440,390}.png`는 초기 로딩 개선 후의 배포용 빌드를 같은 첫 장면에서 멈춰 촬영했다. 두 크기에서 기본 반사·빛줄기 출력과 헤더 굴절 지도 픽셀 해시가 각각 일치한다. 속도는 별도로 영상을 재생한 상태에서 각3회 측정했다. 작은 스크린샷을 누르면 원본으로 열린다.

`reflection-1440-dusk.png`·`reflection-390-night.png`는 실제5173의 새 반사 조절판이다. 재생 아래 별 아이콘 → **반사**를 누르면 밝기·물결 크기·흐름 속도를 조절한다. 모두50%가 기존 모습이며 속도0%는 흐름 정지다. 빛줄기와 같은 공통 제어판을 사용하고 값은 따로 저장한다. 네 시간대×1440/390/320px에서 영상 재생·패널 범위·초점 복귀·아래 콘텐츠의 굴절 준비·푸터를 확인했다.

HTTP 이미지 응답/브라우저 디코딩과 사용자 Windows 화면의 표시 확인은 구별한다. 성능 수치는 소프트웨어 GPU·제한된 CPU/네트워크의 비교값이며 실기기 속도 보장은 아니다. [최신 구현·검사·한계](../../../work/P9-23.md#초기-로딩과-반사-조절-후속).

## 이전 빛줄기·목록 검토본

2026-10-15 실제 localhost:5173 앱을 Playwright Chromium으로 촬영했다. 가상/생성 시안이 아니다. 공개 첫 화면만 담았으며 사용자·설교 원문·관리자 실제 데이터는 포함하지 않는다.

- [빛줄기를 누른 실제 밤 화면](rays-inline-night.png): 1440×900, 반사·빛줄기 켬, 너비65·밝기55·퍼짐60. 별도 조절 버튼 없이 빛줄기 옆에 제어판이 열린다.
- [모바일 제어판](rays-inline-mobile.png): 390×844, 시간대 바 위에 화면 안으로 맞춘다.
- [작게 정리한 지난 퀴즈](archive-compact-day.png): 제목 오른쪽의 어린이·장년 원형 링크, 작은 날짜·장절, 마지막 푸터까지의 실제 화면이다. 로컬 연습용 제목만 담았다.
- [모바일 지난 퀴즈](archive-compact-mobile.png): 390×844. 긴 내용은 native 스크롤로 읽으며44px 선택 영역을 유지한다.

640×480 상한의 효과 버퍼를 유지하며 앱의 멈춤 버튼으로 장면을 고정했다. 네 시간대×1440/390/320px에서 제어판·마지막 목록을 확인했다. 움직임·키보드/터치·저장/복원은 E2E로 별도 검사했다. 현재 조작은 [실제 메인](http://localhost:5173/)의 재생 아래 별 아이콘 → 빛줄기에서 확인한다. HTTP 이미지 응답과 사용자 Windows 화면 표시 확인은 구별한다. 기존 day-controls/night-controls/mobile-controls.png는 별도 조절 버튼이 있던 이전 단계의 기록으로 보존한다.
