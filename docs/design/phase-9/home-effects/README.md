# P9-23 홈 빛줄기와 조절 화면

2026-10-15 실제 localhost:5173 앱을 Playwright Chromium으로 촬영했다. 가상/생성 시안이 아니다. 공개 첫 화면만 담았으며 사용자·설교 원문·관리자 실제 데이터는 포함하지 않는다.

- [낮·PC 조절 화면](day-controls.png): 1440×900, 반사 끔/빛줄기 켬, 너비65·밝기55·퍼짐60.
- [밤·PC 조절 화면](night-controls.png): 같은 크기/설정, 실제 달 방향의 은빛.
- [밤·모바일 조절 화면](mobile-controls.png): 390×844, 같은 설정/화면.

최종640×480 상한의 효과 버퍼로 촬영했다. 각 시간대에서 영상/효과의 재생을 확인한 다음 앱의 멈춤 버튼으로 장면을 고정해 캡처했다. 모션은 별도로 실제 포인터 이동의 시작/중간/도착 위치와 키보드/터치 E2E에서 확인했다. 앱 코드가 바뀌면 정적 캡처와 달라질 수 있다. 현재 조작은 [실제 메인](http://localhost:5173/)의 재생 아래 별 아이콘 → 빛줄기 → 조절에서 확인한다. HTTP 이미지 응답과 사용자 Windows 화면 표시 확인은 구별한다.
