# P9-06 낮·노을·밤 프롬프트 보완 기록

2026-10-09. 이번 범위는 video-kit의 프롬프트·전달 내용 보완이며 **부모 P9-06은 진행 중**이다. 별도 작업 ID를 만들지 않는다. 새벽12:30 선택 영상(`video=billowing`)과 승인된 `prompts/dawn.txt` 원문은 유지한다.

## 수정 근거와 범위

사용자는 낮 결과에서 구름은 경직되고 카메라 이동만 강하다고 보고했다. 시작 HEAD `799ffb0f23b456ec10336414f045c44c69a834ca`의 세 파생 TXT에는 이미5/10·내부 부풀음/소멸·시차·카메라와 독립된 형태 변화가 들어 있었다. 지시 누락으로 판정하지 않는다. 낮 영상/생성 설정을 직접 분석하거나 새 영상을 생성하지 않았으므로 모델 실패 원인은 미확정이다.

낮을 우선해 노을·밤에도 같은 지시 보완을 적용했다. 구름 자체의 둥근 덩어리 형성·상승·국소적인 얇아짐/소멸을 주 동작으로 올리고 서로 다른 위치의 시차를 구체화했다. 차분하지만 보이는5/10, 더 느린 카메라, 양옆/아래 풍성함과 중앙 여백을 유지한다. 시간대별 색·빛·전체 밝기 및 밤의 달/별 문단은 기존과 같다. 정지 사진 이동/확대·고정 층의 시차·표면 무늬 이동만으로 이를 대신하지 않도록 했다.

끝의 개별 구름 윤곽/위치 복원과 정확히 닫힌 카메라 경로를 필수로 두던 접근은 세 파생본에서 제외했다. 자연스러운 반복은 전체 밀도·여백·빛·흐름의 연속성으로 요청하고 구름의 지속적인 변화를 우선한다. 같은 마지막 PNG는 기본 안내에서 제외했다. 정확한 프레임 제약이 변화 억제로 해석될 수 있다는 검토상 가설이며 원인 입증이나 완벽한 루프 보장은 아니다. 상세 기준과 공식 근거는 [README의 v3 설명](README.md#구름-변화-보완-v3)을 따른다.

수정 파일: `prompts/day.txt`, `prompts/dusk.txt`, `prompts/night.txt`, `index.html`, `README.md`, `manifest.json`, 이 기록. manifest는 새벽 `billowing-v2`와 세 파생본 `billowing-v3`을 파일별로 구분한다. v3은 프롬프트 개정 표기이며 새 작업 ID가 아니다.

## 검증

Playwright1.62.1/Chromium의 실제 브라우저 검사와 정적 대조를 통과했다. 새벽을 포함한 네 TXT·펼친 textarea·실제 클립보드·TXT 다운로드가 일치하고 manifest SHA-256도 맞다. 새벽 TXT는 시작 HEAD와 바이트 단위로 같으며 해시는 `65404eb7767da4035cad3451336e32062279fa9f24e255a4aaac34a87b59711e`다. 세 파생본의 색·빛·천체 문단은 기존과 같고 공통 움직임 절도 서로 일치한다. PNG4장의 파일/크기/해시 및 기존 이미지 provenance metadata를 보존했다.

전달 페이지의 기존 CSS/복사 JS는 변경하지 않았다.320/1440/2560px 가로 넘침 없음, 자동 복사 거부 시 전체 수정 프롬프트 선택 경로 정상, runtime error0. 관련 로컬 링크/앵커49개 오류0이며 추가한 Google 공식 프레임 안내를 확인했다. 작업 diff와 커밋 대상으로 선택한 파일의 `git diff --check`를 통과했다. 원래 v2의 움직임 지시와 v3의 우선순위·시차·반복 조건 차이는 직접 검토했다.

검증 근거는 `/tmp/biblequiz-p9-06-video-prompts-01a11eef/verification.json`, `links.json`, `verify.mjs`, `delivery-desktop.png`에 있으며 임시 파일은 Git에 포함하지 않는다. 본 기록이 지속적인 결과 요약이다. 문서/정적 전달 내용만 변경했으므로 lint/typecheck·전체 출시 검사는 반복하지 않았다. 실제 새 영상의 구름 변화·시간대 유지·반복 품질은 검사하지 않았고 성공으로 판정하지 않는다.

## 공통 STATUS/HANDOFF에 반영할 요약

P9-06의 낮·노을·밤 영상 프롬프트를 billowing-v3으로 보완했다. 기존 움직임 지시는 누락되지 않았으며 사용자 보고의 경직 문제에 맞춰 독립된 구름 변화·위치별 시차를 강화하고 정확한 첫/끝 모양 맞춤 제약을 완화했다. 새벽12:30 영상/video=billowing과 billowing-v2 원문, 시간대별 색·빛·밤의 달/별 조건은 보존했다. 새 영상 생성/품질·반복 검수는 미실시이며 부모 P9-06은 진행 중이다. 공통 STATUS/HANDOFF/P9-06 작업 문서는 병렬 유리 UI 대화에서 반영한다.

공통 명세/기록의 “세 파생본은 색·빛·달/별만 변경, 닫힌 카메라 경로 공유” 설명은 v2 당시 상태다. 사용자 승인된 이번 v3 예외를 관련 현재 설명에 반영할 필요가 있다. 이 대화는 `docs/spec/design.md`, `docs/DECISIONS.md`와 공통 상태 문서를 수정하지 않았다.
