구름을 영상으로 옮기기

새벽, 낮, 노을, 밤. 현재 구름 구도와 시간대의 색을 담은 입력 이미지입니다. 각 이미지와 완성 프롬프트를 저장해 직접 영상 생성에 사용하세요.

출력 4K가로 16:98초고정 카메라 · 느린 구름 · 반복

참조 PNG는 원본 크기인 1672×941입니다. 4K는 영상 출력 설정입니다. 글자·UI·산·잔디 없이 하늘만 준비했으며, 색은 이미 이미지에 반영되어 있습니다.

이렇게 넣으세요

  1. 시간대 하나의 이미지 저장과 프롬프트 복사를 누릅니다.
  2. 시작 이미지/First Frame에 PNG를 넣습니다. 마지막 프레임을 지정할 수 있으면 같은 PNG를 넣습니다.
  3. Veo 3.1 Fast 또는 Veo 3.1의 영상 출력을 4K·16:9·8초로 설정합니다. 네 이미지를 한 요청에 함께 넣지 않습니다.
  4. 완료된 MP4 원본을 저장합니다. 반복 경계는 결과 확인 후 보정할 수 있습니다.
