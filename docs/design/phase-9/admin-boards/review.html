2026년 10월 14일 적용 화면입니다. 본문에 붙은 입체적인 인덱스, 점선으로 나눈 현황판, 콘텐츠 창과 투명도를 맞춘 사이드바를 적용했습니다. 실제 React UI에 연습 자료를 표시해 촬영했으며, 이미지를 누르면 원본을 크게 볼 수 있습니다.

퀴즈 관리

현황과 Live의 5:5 비율과 세 가지 바탕색을 유지했습니다. 현황판은 각진 모서리·위아래 선·점선 구분을 사용합니다. 인덱스는 호버해도 본문에서 떨어지지 않으며, 넓은 상단 색 띠와 얇은 반사·그림자로 입체감을 줍니다. 왼쪽 메뉴도 콘텐츠 창과 같은 투명도로 볼 수 있습니다.

참여 기록

행을 펼치면 왼쪽에는 답안과 코멘트, 오른쪽에는 처리 폼이 나타납니다. 점수와 상태를 작은 박스로 구분하고, 실제 제출값은 입력한 칸을 파랑·빈칸을 호박색으로 표시합니다.

문의·삭제 요청

카테고리와 목록이 시안처럼 같은 바탕으로 이어집니다. 접힌 행에는 이름·분류·상태·날짜와 한 줄 미리보기가 보입니다. 펼치면 전체 원문과 상태·답변 폼을 확인할 수 있습니다.

기존 생성 이미지는 재사용했습니다. 실제 화면 이미지에는 개인 자료나 실제 운영 답안을 포함하지 않았습니다.
