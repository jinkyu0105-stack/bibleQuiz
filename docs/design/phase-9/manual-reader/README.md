# 운영 매뉴얼 콘텐츠 시안

2026-10-13 P9-20. 사용자가 `imagegen-frontend-web` 사용을 명시 요청했다. 요청한 한 섹션인 운영 매뉴얼 콘텐츠 패널에 대해 가로 이미지 한 장을 생성했다. 전체 페이지나 다른 섹션을 합친 보드는 아니다.

[시안 원본 파일](reference.png) · [로컬 브라우저에서 시안 보기](http://localhost:5173/docs/design/phase-9/manual-reader/reference.png)

Windows 앱에서 WSL 파일 이미지가 깨질 때는 위 HTTP 주소로 연다. 5173 개발 서버가 실행 중이어야 한다.

## 생성 방향

16:10 가로 패널, 한국어 운영 안내, 왼쪽 약 22% 목차와 오른쪽 읽기 영역. 기존 하늘색 유리 위의 짙은 남색 글자, 명조 제목·고딕 본문, 실행 파랑·안내 자주색·주의 호박색. 오른쪽에는 큰 제목 하나와 얇은 선으로 이어진 세 단계, 아래 작은 주의 안내를 둔다. 중첩 상자·큰 홍보 제목·성경 구절은 넣지 않는다.

이미지는 구도·타이포 위계·여백을 참고하는 시안이다. 그림 속 예시 문구를 제품 사실로 사용하지 않는다. 실제 문장은 저장소 운영 매뉴얼과 서비스 사전을 사용한다. 참고 PNG는 런타임에서 내려받지 않으며 앱 용량에 포함하지 않는다. 기존 하늘과 외부 패널의 모양은 유지한다.

## 구현 대응

`ManualReader`가 목차와 선택한 본문을, `ManualBody`가 안전한 코드·강조·문단·목록을 표시한다. 모바일은 별도 시안 이미지를 만들지 않고 같은 위계를 한 열로 적응시킨다. 주제 선택 시 키보드 초점 이동, 밤·강제 색상, 좁은 폭을 검사한다.

P9-22에서 채워진 단계 번호·연결선·굵은 단계 제목, 느낌표와 전체 테두리가 있는 콜아웃, 목차/서비스 아이콘과 활성 표시까지 실제 화면에 적용했다. 원본 이미지와 문서 내용은 보존했다.
