초광폭 화면: 왜 본문과 설정 패널이 떨어져 있나요?

현재 제품 배치는 바꾸지 않았습니다. A는 실제 앱, B는 같은 화면에 촬영용 CSS만 주입한 비교입니다. 글자·데이터·하늘은 동일하며 이미지를 생성해 만든 화면이 아닙니다.

헤더는 화면 가운데 최대1376px, 페이지 바탕은 최대1440px에서 왼쪽36px·오른쪽104px를 비우고, 우측 설정 패널은 창 끝에서24px에 고정됩니다. 여기에 지난 퀴즈는 별도로1100px까지만 넓어집니다. 본문의 가독성을 위한 폭 제한과 창 끝에 붙는 패널이 조합되어 넓은 화면일수록 빈틈이 커집니다.

1440px인데 캡처는1800px인 이유

DevTools의 화면 너비는 웹 배치에 쓰는 CSS픽셀입니다. 캡처 도구가 세는 물리픽셀은 디스플레이 배율·브라우저 확대·DPR에 따라 다를 수 있습니다. 이번 재현에서는 1440 × 1.25 = 1800이었습니다. 사용자의 실제 배율이1.25라는 뜻은 아니며, 캡처 크기만으로 페이지 잘림을 판단할 수는 없습니다.

재현 값: innerWidth1440, clientWidth1440, scrollWidth1440, devicePixelRatio1.25, PNG1800×1125. 실제 앱도320·375·425·768·1024·1440·2560·3440px에서 가로 넘침0을 확인했습니다. 네 시간대와 선택창·월별 주제 폼을 포함한60상태 측정에서 페이지 오류0입니다. 실제 휴대폰 검수와는 구분합니다.

이번에 실제 적용한 부분

지난 퀴즈는 위에 주차와 월별 주제, 아래에 제목과 성경 장절을 배치했습니다. 좁은 화면에서는 자연스럽게 줄바꿈합니다. 날짜 타일은54px로 줄이고 행의 최소 높이는76px로 맞췄습니다.

관리 공간 → 퀴즈 관리 → 월별 설교 주제에서 달별로 입력·저장할 수 있습니다. 기존 site_state에 저장하므로 새DB테이블이나 migration이 필요 없습니다. 같은 달의 모든 지난 퀴즈에 반영되며 실제 주제를 임의로 채우지 않았습니다.

헤더 ‘이번 주 퀴즈’는 난이도 선택창(모달 대화상자)을 엽니다. 현재 대표 퀴즈의 어린이·장년으로 바로 이동합니다. 공통 부품 모음에도 실제 컴포넌트를 등록했습니다.
