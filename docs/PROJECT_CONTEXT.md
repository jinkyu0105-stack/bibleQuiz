# 프로젝트 맥락

다사랑교회 공동체의 주간 설교로 어린이·장년용 한글 가로세로 퀴즈를 만드는 개인 운영 웹앱이다. 관리자 1명, 예상 주간 방문 약 30명·제출 10~20명·동시 접속 50명 이하를 기준으로 한다. 인프라 월 USD 0을 우선하고 AI API 사용료는 별도다.

## 제품 흐름

영상 링크 → 공개 자막 또는 직접 붙여넣기 → 자막 확인·선택적 AI 교정 → 설교 의도 분석·비판 검토·사람 확정 → 간결한 요약과 어린이/장년 답·단서 → 코드가 격자 배치 → 사람이 확인하고 발행한다.

교정의 주 결과는 수정된 문서 한 벌이다. AI는 짧은 인용문을 반환하고 프로그램이 전체 원문에서 위치/시간을 찾는다. 못 찾거나 여러 곳에 있으면 위치 미확인으로 표시하며 저장·진행은 유지한다. 별도 최종 AI 감사는 제외한다. 만족스럽지 않으면 관리자가 해당 버튼으로 다시 생성하며 자동 AI 재호출은 하지 않는다. 과거 교정·감사 이력은 보존한다.

방문자는 회원가입 없이 풀이·부분 답안 제출·서버 채점·내 답/정답 비교를 이용한다. 진행 중 참여 현황은 제출자에게, 마감 뒤 결과는 공개한다. 빈 격자 PNG/SVG와 단서 복사, Top N 출력이 제품 범위에 포함된다.

## 유지할 기준

- 자막만 수정한다. 목사님 제공 원고·요약본은 받은 그대로 사용한다. 원본은 불변이다.
- 승인된 자막 입력 상한은 공백·줄바꿈 포함 30,000 Unicode code points다. 새 출력 총량 상한은 확정하지 않았다.
- 개역개정 본문을 생성·복사·저장하지 않는다. 장절·판본·공식 읽기 링크만 제공한다.
- 공개 응답에서 정답·비공개 자막·관리자 정보를 분리한다. 제출·삭제·보존 정책을 문서 정리로 완화하지 않는다.

## 기술과 현재 위치

React/TypeScript/Vite·Hono를 Cloudflare Workers + Static Assets로 제공하고 D1/Drizzle을 사용한다. Node24.18.0·pnpm11.14.0. 공개 app, 비공개 content/backup, Preview를 분리한다. Supadata 자동 자막은 app, OpenAI는 content, R2는 backup에만 연결한다.

Phase5·출력·기기·운영 구현/필수 검사와 P8-02·Phase8의 합의된 v1 출시 범위는 완료했다. 실제 새 설교의 자막→AI 생성→사람 검수→3단어 시험 발행과 기존 공개 입력/제출/결과 복원·PDF·백업/격리 복원 근거가 있다. 첫 주간 SQL 예약도2026-10-05 04:00KST에 verified됐다. 완료한 검사는 반복하지 않는다.

기본5×5의 목표 개수 실패는 후보 길이·교차 연결 문제이며 같은 저장 후보로 어린이8×8/5개·장년9×9/6개가 오프라인 성공했다. 프로그램의 크기 제안/후보 조건 전달은 사용자 요청으로 향후 계획에 이관했다. OpenAI5회/USD0.57를 실제 응답과 대조하고 캐시 쓰기 비용 계산을 보완해 소스56bb1bf를 운영 반영했다. Cloudflare2026년10월 현재 예상 사용료0을 사용자 확인으로 대조했다. 미래0원 보장이나 고정 구독료/invoice 직접 조회는 아니다. Supadata 사용량 표시는 사용자 요청으로 출시 후에 검토한다. 일부 계정 지표의 미관측 한계도 보존한다. 관리자 UI 개편의 부모 Phase9는 진행 중이다.
