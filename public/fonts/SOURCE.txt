This static Regular font avoids the Thin default of the variable font.
Runtime exports fetch only the local font; no request goes to Google or an AI provider.
PDF embeds only the glyph subset used by that export.

PDF compatibility: @pdf-lib/fontkit 1.1.1 is patched via pnpm to word-align
TrueType subset glyph records before short loca encoding. The original font
asset is unchanged; regression tests compare original and subset vector paths.
See patches/@pdf-lib__fontkit@1.1.1.patch and docs/work/P6-01.md.
