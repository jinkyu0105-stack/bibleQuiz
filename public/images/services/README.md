# 서비스 사전의 공식 회사 아이콘

2026-10-13에 각 회사의 공식 사이트 또는 공식 GitHub 저장소에서 가져왔습니다. 파일의 모양과 색은 바꾸지 않았습니다. 밝은 중립 바탕 위에 표시해 네 시간대에서도 원래 로고가 보이게 합니다. 회사와 서비스를 식별하기 위한 표시이며, 이 사이트의 자체 로고나 제휴 표시로 사용하지 않습니다. 각 상표의 권리는 해당 회사에 있습니다.

Cloudflare 서비스에는 같은 회사 아이콘을 사용합니다. `서비스 주소`는 회사명이 아니므로 기존 지구본 아이콘을 사용합니다.
